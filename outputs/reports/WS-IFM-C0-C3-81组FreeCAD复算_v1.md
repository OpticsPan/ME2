## 八路输入与两版共用的 Rx、Ryx

直接读取上一次 FreeCAD 0.21.2 的 81 组保存路径，工况 ID、顺序、预设值和原始路径都沿用该批数据。姿态定义为主动旋转、列向量、`R = RotZ(Rz)*RotX(Rx)*RotY(Ry)`，XYZ 为实验室坐标中的平移。每条路径先对其零位扣除，再除以 2。六路直接光程即 `x1–x3、y1–y3`，Z 的每一路取同样归一后的直返减折返，即下表 `z1、z2`。所有公式内部使用 mm、rad。 [原 FreeCAD 工况](WS-IFM-C0-%E5%85%AC%E5%BC%8F%E7%AC%A6%E5%8F%B7%E4%B8%8E%E4%B8%8B%E6%A0%87%E6%A0%B8%E5%AF%B9_v1.md#c0-check-freecad) · [几何坐标和束号](WS-IFM%E6%A8%A1%E5%9E%8B_v2.md#坐标与观测量)

~~~text
mx1 = (x1+x2)/2                 mx2 = x1-x2
my1 = (y1+y2)/2                 my2 = y2-y1
mz1 = (z1+z2)/2                 mz2 = z1-z2

uX  = mx2/(4*cx)                uY  = my2/(4*cy)
vX  = (x3-mx1+dyX*uX)/hx        vY  = (y3-my1-dxY*uY)/hy
Rx  = asin(vY)                  Ryx = asin(-vX/cos(Rx))
~~~

`hx=55 mm、hy=68 mm` 是各方向上束到第三束的高度差。`dyX=-20 mm` 是 X3 相对 X 上束中点的 Y 向偏置，`dxY=+15 mm` 是 Y3 相对 Y 上束中点的 X 向偏置。扣除这两个偏置引入的偏航差后，`vX、vY` 是 X/Y 镜面法向的 Z 分量。此转序下它们分别为 `-cos(Rx)*sin(Ry)` 和 `sin(Rx)`，所以可用六路 XY 光程解出共用的两角。取零位附近的反正弦分支。本批的共用角与预设相差在 `1.8e-9 µrad` 以内，属数值精度量级。 [原式缺少的通道](WS-IFM-C0-%E5%85%AC%E5%BC%8F%E7%AC%A6%E5%8F%B7%E4%B8%8E%E4%B8%8B%E6%A0%87%E6%A0%B8%E5%AF%B9_v1.md#c0-check-missing) · [共用角的几何关系](WS-IFM%E6%A8%A1%E5%9E%8B_v2.md#ryx-解算对比)

逐组先从六路 XY 光程求共用的 `Rx、Ryx`。然后分别代入 C0 和 C3，以对应公式解 `Rzy、Rzx、X、Y、Z、Ryz`。取各版自己的 `Rzy` 作为其 `Rz`，共用的 `Ryx` 作为其 `Ry`。Rzy、X、Y 式右边含待解量，按固定其他输入时的仿射关系 `q=A*q+B` 求 `B/(1-A)`。所有公式求值后回代。预设位姿只用于算误差。C3 执行公式表中的 **5、6、4、3、15、14 项**，总计 47 项。数值为零的项仍保留在求值式中。 [C0/C3 公式表](WS-IFM-C0-C3%E5%85%AD%E5%BC%8F%E5%AF%B9%E7%85%A7_v1.md#c0-c3-formulas)

## 名义常数与待确认项的处理

名义值沿用同一 FreeCAD 布局的几何定义。两版用同一组常数，81 组工况均未用于重新拟合常数。 [机器常数定义](WS-IFM%E6%A8%A1%E5%9E%8B_v2.md#v1-字段怎么代入) · [名义几何值](WS-IFM%E6%A8%A1%E5%9E%8B_v2.md#几何参数表)

| 项或系数 | 两版共同的处理 |
| --- | --- |
| X/Y 余弦项的距离和分解 | `Kx=480、kx=530、Ly=425、ly=380 mm`。用 CAD 等效光头到 O 的距离对应 `Kx、Ly`，`kx` 仍按原件的台体尺寸取值。C3 保留两组距离项的 C0 分解，Y 式保持 `-Ly`，角轴改为 `Rx^2`。距离端点与实机符号仍待确认。 |
| Abbe 臂、水平差分基线 | `ax=43.5、ay=32.5、4*cx=210、4*cy=180 mm`。两版用相同正值，补偿差由公式的符号与角下标产生。 |
| `dd、ee、sxy` | 当前名义光头横偏与非正交取 0。C3 中相关项照算，这组数据无法验证它们在实机中的有向定义。 |
| `Xb、Yb` 及平均、差分束线角 | 以零位等效光程 `Xb=280、Yb=235 mm` 作为占位值。`Ryix0、Rzix0、Rxiy0、Rziy0、dRyixh、dRzixh、dRxiyh、dRziyh` 都取 0。C0 按原式运算顺序读取 `Xb/4*cx、Yb/4*cy`，C3 按除以完整基线读取。端点和上束方向差定义在本组零残差条件下不影响结果。 |
| `ux、wy` | 上束同高的名义几何取 0，两个待确认的失配正向不参与本组口径判断。 |
| Z 式中的 `Ry` | C0 原件第 4 页说明生产 Z 子模型会使用 `Ryz`。本对照沿用此前的几何验证口径，各版的 Z 式都代入同一个 `Ryx`。因此 Z 只比较保留式的差异，避免把 C0 `Ryz` 的原式量纲问题带入 Z。`Ryz` 的计算使用本版解出的 `Z`，其余俯仰补偿使用同一个 `Ryx`。实机 `Ryz→Z` 接口仍待确认。 |
| Z 名义系数 | `ezxa=50、dzxxa=-49.25、dzyya=-698.25 mm`，角度以 rad 代入。`szya、szxa、ezya、ezza、czxya、czxza、czyya、czxxa、dzzza、dzxza` 均取 0。 |
| Ryz 的尺度和有效臂 | `kze=554 mm`，四个外乘尺度 `sfx、sfy、sfz、sfryz` 均取数值 1。C0 原式照算含倒臂平方的主项。C3 用 `mz2/(kze+2*Z)`。没有用拟合比例把 C0 的结果抬到与 C3 相同的增益。 |
| Ryz 其余项 | `drxza=-980/554` 沿用此前名义取值。`srxa、srya、srza、erxa、erza、crxxa、crxya、crxza、drxxa、dryya` 取 0。`dryya*Ry` 暂按原文的一次幂保留，零系数无法辨识它应使用一次还是平方。 |

`C0 Ryz*` 是照抄原式求出的数值乘以 `10^6`。`误差*` 为该数值减去预设 `Ry` 的 µrad 数值，方便对照量级。原主项在长度用 mm 时为倒长度，故星号列只用于数值诊断。若只为比较高度斜率，在 `X=Y=Rx=Rz=0、Ry=800 µrad` 的三组中，把预设 Z 代入两版 Ryz 的首项，并仅对 C0 首项乘 `554`，使零位增益相同。`Z=-5、0、+5 mm` 时，C0 首项得到 `814.175、800.000、785.303`，C3 首项得到 `799.999625、799.999621、799.999617 µrad`。此试算只比较高度增益，和下方的全式逐组表分开。 [Ryz 首项核对](WS-IFM-C0-%E5%85%AC%E5%BC%8F%E7%AC%A6%E5%8F%B7%E4%B8%8E%E4%B8%8B%E6%A0%87%E6%A0%B8%E5%AF%B9_v1.md#c0-check-ryz) · [Z 的输入说明](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#z-ifm-原式)
