## C0 原式与名义参数

原式以《ifm模型.docx》**第 1 页**的 X、Y、Rzx、Rzy 与**第 4 页**的 Z、Ryz 为准。第 2 页将 `ay` 的效应列为 Y(Rx)，第 1 页公式写 `+ay·Ry`，本次 C0 按第 1 页执行。第 4 页的 `mz2·((1−2Z/kze)/kze)²` 和 `dryya·Ry` 保留字面形式。第 5 页定义 `kze` 为 Z 两路的有效臂。原件阐述 Ryz 用于 Z，但所列 Z 式只含 `Ry`。本次按 v5 的主俯仰输入 `Ry=Ryx` 代入。X、Y 的自项仅做代数移项。C0 缺少 Rx 和 Ryx 的独立式，两列共用由同组读数得到的 v5 补充式，原 C1 同样使用这两个角度。[原始公式转录](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#xy-ifm-原式)

| 参数 | 本次 C0 输入 | 来源和约定 |
| --- | --- | --- |
| `Kx、Ly、ax、ay、4cx、4cy、ly` | 480、425、43.5、32.5、210、180、380 mm | v5 名义光头、束间距和镜面坐标。 |
| `kx` | 530 mm | DOCX 第 2 页定义为台体 X 尺寸。v5 网格外包络 X 为 ±265 mm，光学代码的 `cfg.kx=400 mm` 是两片 X 镜面间距，修正 C1 按该光学间距计算。 |

| `kze` | 554.000000 mm | 用 v5 名义光路在零位 ±1 µrad 扰动求 `∂mz2/∂Ry`，与 DOCX 有效臂定义对应。 |
| `ezxa、czxya、dzxxa、dzyya、dzzza` | 50、1、843.25、2436.75、457.5 | 按 DOCX Z 式的系数槽位，从原 v5 光路在名义零位的局部导数求出。平移扰动 1 mm，角度扰动 0.1 mrad。位置和角度按 mm、rad 代入。 |
| `drxza` | 5.67509 | 从名义 `mz2/kze` 对 Rx·Rz 的响应取补偿系数。 |
| 其余机台参数 | 置零或名义舍入量级 | v5 未给出装配失配、非正交或实机镜面图。局部导数来自名义光路，121 帧扫描和校验位姿未参与求取。 |

C0 的峰值 X、Y 平移误差分别出现在第 101、22 帧。其主要一阶来源与此前 FreeCAD 单轴验证一致：X 使用 `−ax·Ry`，而名义 X 光程均值本身随 Ry 减少；Y 使用 `+ay·Ry`，而该路主 Abbe 响应来自 Rx。[原始 v1 一阶验证](WS-IFM%E5%8E%9F%E5%A7%8Bv1%E4%B8%80%E9%98%B6FreeCAD%E9%AA%8C%E8%AF%81_v1.md#zero-pose-slopes)

## C1 残差来源

复算保留 v5 原 `rng(7)` 生成的 250 组标定输入、Z/Ryz 线性回归及运行时求值。C1 的 121 帧输出通过逐元素相等检查。v5 的坐标映射为 `p_world = R·(p_local+T)`，其中 `T=[X,Y,Z]ᵀ` 是旋转前的平移，`R=RotX(Rx)·RotY(Ry)·RotZ(Rz)`。报告与 CSV 的 XYZ 均沿用这个 T。由于转序、输出坐标及光程定义与以前的 FreeCAD 法向回射模型不同，以前的系数不能直接移入 v5。

| 残差来源 | v5 中的表现 | 修正依据 |
| --- | --- | --- |
| Rx 交叉项 | Y 三束未经反解的法向 Z 分量已含 `+Ry·Rz` 的二阶贡献，C1 又加 `Ryx·Rzy`。 | `2·Ry·Rz` 解释了 1.800 µrad 峰值。减去该项后，121 帧的差异最大仅 0.000993442 µrad。 |
| Ryx 横向偏置 | X3 的横向偏置项用 Y 路偏航替代 X 路上两束差分，另有 X 面的 Rx·Rz 分量。 | 程序的二阶误差为 `−Rx·Rz + (δy_X/hx)·Rx·Ry`。扣除该预测后的最大差异为 0.00150489 µrad。 |
| X/Y 平移 | C1 用近似姿态和迭代余弦项。Rx/Ryx 误差经 Abbe 臂带入平移。 | 由四段 XY 光程的精确几何式求法向和 T。原 X/Y 残差的二阶预测分别为 `ax·(δy_X/hx)·Rx·Ry`、`−ay·Ry·Rz`，剩余峰值分别为 0.514、0.258 nm。 |
| Z 和 Ryz 拟合 | C1 的 `kze=465 mm` 是 45° 面中心水平间距。该仿真的 Z 差分零位有效臂约为 554 mm。拟合的 Ryz 总增益 0.83932016 接近 465/554，但模型仍有残差。 | 仅作诊断时，把 C1 的拟合式直接输入预设 XYZ/Rx/Ry/Rz，Z 仍有 46.872 nm、Ryz 仍有 0.372164 µrad 的最大误差。改按实际折返光程求逆，无需以这组多项式拟合替代光程。 |

<a name="corrected-equations"></a>

## 修正 C1 的解算式

v6 保持 v5 的光线追迹及计数倍率：X/Y 是二次往返累计长度变化除以 4，Z 各路是直返减折返的往返增量除以 2。均差量沿用 `mx1、mx2、my1、my2、mz1、mz2`。下式中 `n` 是镜面单位法向、`d` 是入射单位方向、`H` 是读数头位置、`P` 是镜面上的点。

### X/Y 光程、姿态与平移

对 v5 的理想角锥回射构造，四段路径长度满足 `L/4=(n·d)(n·(P−H))`。第一次到镜面距离为 `s`，第二次从展开后的虚点到镜面距离为 `2s`，最后一段回程为 `s·(4(n·d)²−3)`，三段求和得到该式。

```text
uX = mx2/(4cx)                        uY = my2/(4cy)
vX = (x3−mx1+δy_X·uX)/hx              vY = (y3−my1−δx_Y·uY)/hy
sX = √[(1+√(1−4(uX²+vX²)))/2]         sY = √[(1+√(1−4(uY²+vY²)))/2]
nX = (sX, uX/sX, vX/sX)ᵀ              nY = (−uY/sY, sY, vY/sY)ᵀ
nZ = nX × nY
Rx  = atan2(−nZ_y, nZ_z)
Ryx = atan2(nZ_x, hypot(nZ_y,nZ_z))
pX = RotY(−Ryx)·RotX(−Rx)·nX          pY = RotY(−Ryx)·RotX(−Rx)·nY
Rzx = atan2(pX_y,pX_x)                Rzy = atan2(−pY_x,pY_y)

X = (mx1+280)/sX + 200 − Kx·sX − ax·nX_z
Y = (my1+235)/sY + 190 − Ly·sY − ay·nY_z
```

`sX、sY` 取靠近零姿态的正根。`hx/hy=55/68 mm`，`δy_X/δx_Y=−20/+15 mm`。`280、235 mm` 是上束名义四分之一光程。`200、190 mm` 是光学 X/Y 镜面至台体原点的轴向距离，程序从已有几何定义计算。

### Z 与冗余 Ryz

固定角度后，各反射面的法向保持不变，平面与光线交点的路径参数随 T 线性变化。固定已解算的 X、Y、Rx、Ryx、Rzx，令 `g(Z)` 为前向光路的 `mz1`。在此固定姿态下 `g` 对 Z 为仿射函数。

```text
Z = [mz1 − g(0)] / [g(1 mm) − g(0)] · 1 mm
Ryz = θ 满足 m_z2(X,Y,Z,Rx,θ,Rzx) − mz2 = 0
```

v6 在 ±5 mrad 的名义分支内用标量求根，从 Z 差分另读 Ry。额外 79 组在该区间取 11 点检查，差分的最小相邻斜率为 546.917 mm/rad。将第 61 帧的 `mz2` 单独加 10 nm，Ryz 增加 0.01805924 µrad，Ryx 保持原值。

## 独立验证

| 场景 | 数据来源 | 修正 C1 最大位置 / 最大角度误差 |
| --- | --- | --- |
| 121 帧原扫描 | MATLAB R2024b 原 v5 的光程和轨迹 | 3.09e-07 nm / 2.59e-09 µrad |
| 79 组独立预设 | 15 组零位、单轴和端点组合，加 64 组 `rng(21)` 预设，范围 XYZ ±100/100/0.4 mm、转角 ±1.2 mrad | 3.16e-07 nm / 8.87e-09 µrad |
| 136 组 FreeCAD 读数 | FreeCAD 0.21.2 按 v5 的转序、体坐标平移和计数倍率，使用 CAD 实体面重走 121 帧及 15 组复核位姿 | 3.12e-07 nm / 3.41e-09 µrad |

FreeCAD 用《ws-ifm-agent.FCStd》的实际移动镜面和固定 Z 镜面读取十条光程，136 组的镜面交点均在有限面内。两套软件的八路输入最大差为 **3.98e-07 nm**，用解算结果回投时最大光程残差为 **9.66e-07 nm**。FreeCAD 验证副本在本机 `work/ws-ifm-matlab-simulation-v1/WS-IFM-C1-FreeCAD交叉验证_v1.FCStd`，已保存并重开比对位姿和光程。

这些结果验证了指定理想光路的前向/反向一致性。测试未加入实机束线失配、触发采样、探测器收光孔径、读数噪声或实际装调机器常数。旧版拟合系数的实机复用依据见 [机器常数校准项目](WS-IFM%E6%9C%BA%E5%99%A8%E5%B8%B8%E6%95%B0%E6%A0%A1%E5%87%86%E9%A1%B9%E7%9B%AE_v1.md#parameter-evidence)。
