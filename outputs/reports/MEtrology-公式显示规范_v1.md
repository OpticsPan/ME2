# MEtrology 公式显示规范

自 2026-11-25 起，**MEtrology 的正文、审阅草稿、图表及由其导出的 PDF 中，公式一律以已排版的图片显示。** 每条独立公式沿用章节编号，同一公式在不同位置使用同一编号。图内使用公式时将排版后的数学式绘入图中。

在 Markdown 中嵌入公式图片。替代文字写明公式编号及用途，紧邻的正文解释各符号的物理含义。正文可以直接使用参数名、标记名、数值和单位。
