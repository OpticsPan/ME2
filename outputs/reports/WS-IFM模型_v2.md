## 验证结论

**v1 原式不能按字面直接用于当前 FreeCAD 布局。** Y 的一阶 Abbe 补偿轴应为 Rx。按本报告的右手坐标和光程正号，X/Y 的平移补偿分别是 `+ax·Ry` 和 `−ay·Rx`，Z 差分的名义 Ry 灵敏度是 **554 mm/rad**，并随高度变为 **`554 mm + 2·ΔZ`**。v2 给出经过 FreeCAD 几何及 MATLAB 光程计算交叉验证的一阶反解和有限转角求解方法。原附件的公式、字段和待核对项见 [原始模型 v1](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md)。

Y 的转轴错误可用单轴反例直接判定。在其他量为零时，施加 `Ry = +100 µrad`，理想 Y 双束平均光程增量为零，原式 `+ay·Ry` 按 CAD 中的正值高度差会凭空产生 **3.25 µm** 一阶 Y 修正。反过来，施加 `Rx = +100 µrad` 会产生约 **+3.248 µm** 的 Y 平均光程变化。

## 修正后方程

### 名义位姿的一阶反解

台体上点 `p` 的一阶位移是 `v(p)=Δ+ω×p`，其中 `ω=(Rx,Ry,Rz)`。X/Y 直接通道取其在入射方向上的投影。Z 折返路的长度变化取移动折点的入射方向减折出方向投影，固定镜上命中点的移动沿镜面切向。将其与直返路相减得

```text
dᵢ = eZ · v(Fᵢ) + uᵢ · [v(Pᵢ) − v(Fᵢ)]，u₁=+eX，u₂=−eX

           ΔX   ΔY   ΔZ     Rx      Ry      Rz
x1          1    0    0       0   −43.5     105
x2          1    0    0       0   −43.5    −105
x3          1    0    0       0   −98.5      20
y1          0    1    0    32.5       0     −90
y2          0    1    0    32.5       0      90
y3          0    1    0   100.5       0      15
d1          0    0    1     −50     277       0
d2          0    0    1     −50    −277       0
```

列系数乘位姿向量得到 mm。名义一阶矩阵 `J₀` 的 XY 六路秩为 5，合并 Z 两路后秩为 6。需要分通道计算时，可用以下修正方程。

```text
Rzx = mx2 / 210
Rzy = my2 / 180
Rz  = (Rzx + Rzy) / 2                       # 理想等权示例
Ryx = (mx1 − x3 + 20·Rz) / 55
Rx  = (y3 − my1 − 15·Rz) / 68

ΔX  = mx1 + 43.5·Ry
ΔY  = my1 − 32.5·Rx
ΔZ  = mz1 + 50·Rx
Ryz = mz2 / 554
```

`Ry` 可采用 X 通道的 `Ryx`，`Ryz` 可作独立对照。第三束的横向偏置产生 `Rz` 项，做上下束差时须保留。在需要利用全部观测时，从 `J₀ q = (x1,x2,x3,y1,y2,y3,d1,d2)ᵀ` 直接求最小二乘位姿，实测噪声权重按通道确定。

### Z 差分的高度修正

`465 mm` 是名义两折点的 X 向间距。直返点比折点高 `44.5 mm`，每一路还贡献 `±44.5 mm/rad`，故差分灵敏度为 `465+2×44.5=554 mm/rad`。台体先纯升高 `ΔZ`，左右水平束与斜面的交点各向外移 `ΔZ`，直返与折返水平束的高度差仍为 `44.5 mm`。因此在给定高度附近对小 `Ry` 有

```text
Kgeo(ΔZ) = 554 mm + 2·ΔZ
∂(d1−d2)/∂Ry = Kgeo(ΔZ)
Ryz ≈ mz2 / Kgeo(ΔZ)     # 围绕纯高度偏置的一阶式
```

`Kgeo` 是本 CAD、本文光程归一化下的等效灵敏度，实机 `kze` 要结合该机的读数定义核对。当 X 与转角同时变化时，使用下节的有限姿态方程。

### 有限姿态的正向计算和反解

对移动平面上一点 `a` 和单位法向 `n`，按 `a(q)=R·a+Δ`、`n(q)=R·n` 更新。光头固定，记其 CAD 光路起点为 `s`。理想镜面下采用从同一光头出发并返回的驻值路径。

```text
直返等效光程 ℓD(q) = |n(q) · (a(q) − s)|

设 A 是变换后的移动折镜，B 是固定框架镜。
将 B 在 A 上镜像展开：
    b' = b − 2·nA·[nA·(b − aA)]
    nB' = nB − 2·nA·(nA·nB)
折返等效光程 ℓF(q) = |nB' · (b' − s)|

xᵢ、yᵢ = ℓD(q) − ℓD(0)
dᵢ = [ℓD,ref(q) − ℓF(q)] − [ℓD,ref(0) − ℓF(0)]
```

沿展开光路与 A 求交，再把虚拟固定镜命中点折回 B，即可检查各反射点是否落在真实镜面口径内。令上述计算为 `f(q)`。先以 `q₀ = J₀ \ m` 为初值，再按 `q ← q + J(q) \ [m−f(q)]` 迭代，其中 `J(q)` 是 `f` 的 Jacobian，反斜杠表示最小二乘解。本文用中心差分求 `J(q)`。若旋转已知，X/Y 平均读数也可直接解二维线性方程。令 `nX=R·eX`、`nY=R·eY`、`Sx,Sy` 为各上层光头的中点，则 `mx1=nX·(Δ−Sx)+Sxₓ`，`my1=nY·(Δ−Sy)+Syᵧ`，并有精确差分 `mx2/(4cx)=nXᵧ`、`my2/(4cy)=−nYₓ`。

## v1 原式逐项核对

v1 保留《ifm模型.docx》第 1、4–5 页原式，第 2–3 页给出 Abbe 臂、束间距和方向失配字段。下表的修正限定在本文冻结的 CAD、坐标、转序和光程正号。

| v1 项 | 当前布局的核对结果 |
| --- | --- |
| X 的 `−ax·Ry` | 对正值几何高度差 `ax`，应为 **`+ax·Ry`**。纯 `Ry=+100 µrad` 时，X 均值为 `−4.352 µm`。直接扣正值 Abbe 项会把一阶误差加倍。带符号的实机 `ax` 必须先转换。 |
| Y 的 `+ay·Ry` 和第二个 `Ly` 角度因子 | Abbe 修正按本文正号是 **`−ay·Rx`**。Y 面的方向余弦二阶因子为 `Rx²+Rz²`。纯 `Ry` 绕 Y 面法线转动，在测试的理想居中光路中不改变 Y 光程。原式用 `Ry` 的两处均与当前几何冲突。原机的 `Ly` 距离基准按机型另核。 |
| `Rzx`、`Rzy` 的 `4cx`、`4cy` | 正确，前提是按本文顺序取差。纯 `Rz=100 µrad` 时，两通道差除以相应束间距均为 `99.9999998 µrad`。 |
| `Rzx` 的 `−Rx·Ry`，`Rzy` 无对应项 | **与 `R=Rz·Rx·Ry` 的二阶结果一致**。在真 `Rz=0`、`Rx=Ry=1 mrad` 时，原始 X/Y 差分换算约为 `+1/0 µrad`，修正后两者约为零。若改用 `Rz·Ry·Rx`，原始换算约为 `0/−1 µrad`，此时照搬分配会在两通道各留下约 `−1 µrad`。 |
| `Xb/4*cx`、`Yb/4*cy` | 若 `Xb`、`Yb` 是长度，字面左结合后有长度平方量纲，需明确为 `Xb/(4cx)`、`Yb/(4cy)` 才给无量纲比例。CAD 未定义这两个基准长度和束线误差角，v2 用精确法向与光路计算绕开这些未定映射。 |
| Z 的 `mz1`、`ezxa·Rx` 和显式 `+X·Rx·Rz` | 单位尺度下 `mz1` 正确响应纯 Z。对 O，`mz1` 的 Rx 耦合为 `−50 mm/rad`，反解加 `50·Rx`。混合扰动隔离出 `mz1` 自带 **`+ΔX·Rx·Rz`**，反解中对应 **取减号**。其他二阶项按有限姿态光程计算。 |
| `Ryz` 的 `mz2*((1-2*Z/kze)/kze)^2` 及 X 乘转角平方项 | 若按 v1 的定义把 `mz2` 读为长度，该项的单位为长度的倒数，同括号内 `(X/kze)·角度²` 无法直接相加。本文从 CAD 得到 `mz2/Kgeo` 及其高度依赖。将 `ΔX` 与单轴转角平方分离时，差分中已有 `+ΔX·Rx²` 和 `+3ΔX·Ry²` 的长度项，反解需扣除其贡献，再除以几何灵敏度。v1 的正 `2/kze`、`4/kze` 项不能直接用于当前约定。 |

尺度因子、台体非正交、固定镜倾斜、光束失配、镜面图、通道基准与控制器补偿字段仍需对应机型数据。v1 的 `dd/ee` 定义与正文分配也须结合目标机的报表定位，见 [v1 的字段差异](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#原件差异与实现边界)。

## 数值验证

用 **FreeCAD 0.21** 原生重新打开本机《ws-ifm-agent.FCStd》，核对镜块、条形镜、晶圆、坐标轴和光路共 17 个对象的顶点，以及两路上折对固定镜下表面的命中。读取后关闭文件，源文件 SHA-256 复查一致。MATLAB R2024b 用镜像展开求理想往返光程，逐点检查反射点在有限镜面口径内。名义 Jacobian 用 `1e−3 mm`、`1e−5 rad` 的中心差分，解析与数值的最大系数差为 `2.30×10⁻⁸`（相应列单位）。

| 独立检查 | 结果 |
| --- | --- |
| 各轴分别平移 `+0.100 mm`，无转角 | X 仅响应 X 三束，Y 仅响应 Y 三束，Z 仅响应两路 Z。各响应均为 `+0.100 mm`。 |
| 单轴转动 `+100 µrad` | `Ry` 产生 X 上束平均 `−4.352 µm`、Y 上束平均为零。 `Rx` 产生 Y 上束平均 `+3.248 µm`、Z 均值 `−5.000 µm`。 |
| `ΔZ = −5, −1, 0, +1, +5 mm` 时对 Ry 做中心差分 | Z 差分灵敏度为 `544、552、554、556、564 mm/rad`，与 `554+2ΔZ` 一致。 |
| `ΔX=±1 mm`，角度步长依次 `2、1、0.5 mrad` | 混合差分趋于 `∂³mz1/∂X∂Rx∂Rz=+1`，`mz2` 的 `X·Rx²`、`X·Ry²` 系数趋于 `+1、+3`。 |
| 192 组组合位姿 | 均匀采样范围 `ΔX,ΔY∈±0.10 mm`、`ΔZ∈±0.05 mm`、各转角 `±100 µrad`。一阶近似最大光程差 `20.72 nm`，均方根 `4.43 nm`。用一阶线性矩阵反解，最大平移误差 `16.18 nm`，最大转角误差 `23.14 nrad`。 |
| 同一批样本的有限姿态反解 | 以一阶解为初值，做三次 Gauss–Newton 更新。最大光程闭合差小于 `10⁻⁶ nm`，位姿恢复误差小于 `10⁻⁶ nm`（平移）及 `2×10⁻⁶ nrad`（转角），处于本算例的数值舍入量级。 |

这些误差来自同一理想几何模型中的合成数据。复算时，零位等效直返光程 X 三束均 `280 mm`、Y 三束均 `235 mm`，两路 Z 折返 `595 mm`、直返 `290 mm`，各路直返减折返名义量为 `−305 mm`，计算增量时先扣除。数值复算脚本在本机 `work/ws-ifm-formula-validation-v1/verify_ifm_formula_v1.m`，随机种子 `20261121`（twister）。

## 实机数据对接

Z 通道的实机读数需要确认是单程、往返还是仪器内部换算后的差分，再用已知的纯 Z 位移、纯 Rx/Ry 及多个 Z 高度的 Ry 扫描核对尺度、符号和耦合。XY 以独立的纯 Rx、Ry、Rz 及平移扫检确认轴向。校准和复验见 [WZIM](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#wzim)、[WGIM](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#wgim)、[WTAF](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#wtaf)、[WZTD](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#wztd) 和 [WGTD](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#wgtd)。当前 v2 对应这份 CAD 的测量侧理想几何，实机高阶补偿和曝光侧参数须按对应工位及版本标定。
