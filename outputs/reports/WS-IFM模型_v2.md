## 验证结论

**v1 原式不能按字面直接用于当前 FreeCAD 布局。** Y 的一阶 Abbe 补偿轴应为 Rx。按本报告的右手坐标和光程正号，X/Y 的平移补偿分别是 `+ax·Ry` 和 `−ay·Rx`，Z 差分的名义 Ry 灵敏度是 **554 mm/rad**，并随高度变为 **`554 mm + 2·ΔZ`**。v2 给出经过 FreeCAD 位姿与光路实体验证的[八路逐项解算](#八路读数的逐项解算)，保留一阶近似和有限姿态联合反解作对照。原附件的公式、字段和待核对项见 [原始模型 v1](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md)。

Y 的转轴错误可用单轴反例直接判定。在其他量为零时，施加 `Ry = +100 µrad`，理想 Y 双束平均光程增量为零，原式 `+ay·Ry` 按 CAD 中的正值高度差会凭空产生 **3.25 µm** 一阶 Y 修正。反过来，施加 `Rx = +100 µrad` 会产生约 **+3.248 µm** 的 Y 平均光程变化。

## 八路读数的逐项解算

本节把 X/Y 三束及两路 Z 差分直接换算为 **`X、Y、Z、Rx、Ryx、Ryz、Rzx、Rzy`**。其中 Ry 和 Rz 各有两个估计，对应六个独立位姿量。下列公式沿用 [坐标与观测量](#坐标与观测量) 的长度、正号和转序，`X、Y、Z` 指相对零位的 `ΔX、ΔY、ΔZ`。解算顺序为 **Y 面法向 → Rx、Rzy → X 面法向 → Ryx、Rzx → X、Y、Z → Ryz**。平移以 `Ryx` 和 `Rzy` 重建朝向，另外两项独立保留作对照。

### 从 X/Y 六束求四个角度读数

同组直接光束的差会消去台体平移和镜面基准点。设 `n_X`、`n_Y` 为从各自三束恢复的单位法向，均取名义正向分支。上束光头间距给出法向横向分量，第三束相对上束中点的横向和高度偏置给出法向 Z 分量。

```text
nY_x = −my2/180
nY_z = (y3 − my1 + 15·nY_x)/68
nY_y = √(1 − nY_x² − nY_z²)

Rx  = asin(nY_z)
Rzy = atan2(−nY_x, nY_y)

nX_y = mx2/210
nX_z = (x3 − mx1 − 20·nX_y)/55
nX_x = √(1 − nX_y² − nX_z²)

Ryx = asin(−nX_z/cos Rx)
Rzx = atan2(nX_y, nX_x) − atan2(sin Rx·sin Ryx, cos Ryx)
```

例如，X3 光头相对 X1/X2 光头中点偏 `−20 mm`（Y）和 `−55 mm`（Z），因此 `x3−mx1=20·nX_y+55·nX_z`。Y3 的对应关系为 `y3−my1=−15·nY_x+68·nY_z`。在所用转序下，`nY_z=sin Rx`、`nX_z=−cos Rx·sin Ry`，X 面法向的 XY 投影方位为 `Rz+atan2(sin Rx·sin Ry, cos Ry)`，由此直接得到上述四式。平方根和反三角函数取零位附近的有效分支，读数超出其定义域时应报输入异常。

### 从三个平均读数求 X Y Z

记 `eX、eY、eZ` 为固定坐标轴单位向量。用上一步得到的 `Rx、Ryx、Rzy` 组装 `R=RotZ(Rzy)·RotX(Rx)·RotY(Ryx)`，并令 `p=R·eX、n=R·eY、w=R·eZ`。`p、n、w` 是用于平移计算的一组正交方向。平移计算采用 `Rzy`，`Rzx` 继续独立保留。各上层光头的中点为 `Sx=(−480,0,−43.5)`、`Sy=(0,−425,−32.5)`，坐标单位 mm。

Z 直返及折返光头中点分别记为 `SP=(0,−50,−114.5)`、`SF=(0,−50,−159)`。两路对称分布在 `X=±H`，`H=490 mm`。折转镜面的公共位置常数为 `CF=−73.5 mm`，来自左折点 `Fx−Fz`，右折点用 `−Fx−Fz` 得到同值。令 `a=p_z`、`b=w_z`。对待求平移向量 `t=(X,Y,Z)` 定义

```text
C(t) = CF + H·p_x − w·(t − SF)
E(t) = p·(t − SF) − H·w_x
K    = −200 − 178.5 + SF_z + H·p_x

Z 均值正向式：M(t) = K + a·E(t) − b·C(t) + 305
M0 = M(0)                         # 仅由已解出的转角计算
```

其中 `−200 mm` 为两路直返移动镜面在各自入射轴上的名义投影，`178.5 mm` 为固定镜面高度，`+305 mm` 用于扣除零姿态的直返减折返名义量 `−305 mm`。对已知转角，Z 均值的平移分量正好是 `a·(p·t)+b·(w·t)`。X/Y 均值分别确定 `p·t` 和 `n·t`，因此可以逐项求出三个投影并重建平移。

```text
TP = mx1 + p·Sx − Sx_x
TN = my1 + n·Sy − Sy_y
TW = (mz1 − M0 − a·TP)/b

X = TP·p_x + TN·n_x + TW·w_x
Y = TP·p_y + TN·n_y + TW·w_y
Z = TP·p_z + TN·n_z + TW·w_z
```

这里使用 `b=w_z≠0` 的工作姿态分支。在零位附近展开，得到原一阶关系 `X≈mx1+43.5·Ryx`、`Y≈my1−32.5·Rx`、`Z≈mz1+50·Rx`。

### 从 Z 差分单独求 Ryz

令待解角为 `θ=Ryz`。固定已求的 `t、Rx、Rzy`，以 `k=cos Rx`、`e=(cos Rzy,sin Rzy,0)`、`f=(sin Rzy·sin Rx,−cos Rzy·sin Rx,k)` 表示不含 θ 的两方向。此时 `p(θ)=e·cos θ−f·sin θ`，`w(θ)=e·sin θ+f·cos θ`。

由镜像展开可得，左路取 `σ=+1`，右路取 `σ=−1`。两路半往返长度为

```text
ℓref,σ  = −200 + H·p_x + σ·p·(t−SP)
ℓfold,σ = 178.5 − SF_z − (σ·a−b)·[C(t)+σ·E(t)]
```

于是对 `ℓref,σ−ℓfold,σ` 求平均得到上节的 `M(t)`。两路作差并代入 `p(θ)`、`w(θ)`，得到仅含 θ 的标量关系。

```text
CD = H·k·f_x
A  = e·(t−SP)
B  = −f·(t−SP) − k·CF
C  = −k·e·(t−SF)
E  = k·f·(t−SF)

mz2/2 = CD + A·cos θ + B·sin θ + C·cos(2θ) + E·sin(2θ)
```

令 `u=tan(θ/2)`、`F=CD−mz2/2`。将三角式改写为四次标量多项式，取工作范围内的实根。

```text
(F−A+C)·u⁴ + (2B−4E)·u³ + (2F−6C)·u² + (2B+4E)·u + (F+A+C) = 0
Ryz = 2·atan(u)
```

若最高次系数为零，按实际次数求根。用 `±5 mrad` 检查本批数据的近零分支，每组均有唯一实根，`∂mz2/∂θ` 在该分支内的保守下界为 `543.96 mm/rad`。选根依据工作分支，`Ryx` 不作为选根目标。整个流程中，五个角度解算量和三个平移量由上述各式顺序给出，只有 `Ryz` 需要求一个标量多项式的根。

## 修正后方程

### 名义位姿的一阶反解

台体上点 `p` 的一阶位移是 `v(p)=Δ+ω×p`，其中 `ω=(Rx,Ry,Rz)`。X/Y 直接通道取其在入射方向上的投影。Z 折返路的长度变化取移动折点的入射方向减折出方向投影，固定镜上命中点的移动沿镜面切向。将其与直返路相减得

```text
dᵢ = eZ · v(Fᵢ) + uᵢ · [v(Pᵢ) − v(Fᵢ)]，u₁=+eX，u₂=−eX

           ΔX   ΔY   ΔZ     Rx      Ry      Rz
x1          1    0    0       0   −43.5     105
x2          1    0    0       0   −43.5    −105
x3          1    0    0       0   −98.5      20
y1          0    1    0    32.5       0     −90
y2          0    1    0    32.5       0      90
y3          0    1    0   100.5       0      15
d1          0    0    1     −50     277       0
d2          0    0    1     −50    −277       0
```

列系数乘位姿向量得到 mm。名义一阶矩阵 `J₀` 的 XY 六路秩为 5，合并 Z 两路后秩为 6。需要分通道计算时，可用以下修正方程。

```text
Rzx = mx2 / 210
Rzy = my2 / 180
Rz  = (Rzx + Rzy) / 2                       # 理想等权示例
Ryx = (mx1 − x3 + 20·Rz) / 55
Rx  = (y3 − my1 − 15·Rz) / 68

ΔX  = mx1 + 43.5·Ry
ΔY  = my1 − 32.5·Rx
ΔZ  = mz1 + 50·Rx
Ryz = mz2 / 554
```

`Ry` 可采用 X 通道的 `Ryx`，`Ryz` 可作独立对照。第三束的横向偏置产生 `Rz` 项，做上下束差时须保留。在需要利用全部观测时，从 `J₀ q = (x1,x2,x3,y1,y2,y3,d1,d2)ᵀ` 直接求最小二乘位姿，实测噪声权重按通道确定。

### Z 差分的高度修正

`465 mm` 是名义两折点的 X 向间距。直返点比折点高 `44.5 mm`，每一路还贡献 `±44.5 mm/rad`，故差分灵敏度为 `465+2×44.5=554 mm/rad`。台体先纯升高 `ΔZ`，左右水平束与斜面的交点各向外移 `ΔZ`，直返与折返水平束的高度差仍为 `44.5 mm`。因此在给定高度附近对小 `Ry` 有

```text
Kgeo(ΔZ) = 554 mm + 2·ΔZ
∂(d1−d2)/∂Ry = Kgeo(ΔZ)
Ryz ≈ mz2 / Kgeo(ΔZ)     # 围绕纯高度偏置的一阶式
```

`Kgeo` 是本 CAD、本文光程归一化下的等效灵敏度，实机 `kze` 要结合该机的读数定义核对。当 X 与转角同时变化时，使用[逐项解算的 Z 标量方程](#从-z-差分单独求-ryz)或下节的有限姿态光程。

### 有限姿态的正向计算和反解

本节的联合迭代保留作交叉验证。当前布局可按[八路逐项解算](#八路读数的逐项解算)直接求出各量。

对移动平面上一点 `a` 和单位法向 `n`，按 `a(q)=R·a+Δ`、`n(q)=R·n` 更新。光头固定，记其 CAD 光路起点为 `s`。理想镜面下采用从同一光头出发并返回的驻值路径。

```text
直返等效光程 ℓD(q) = |n(q) · (a(q) − s)|

设 A 是变换后的移动折镜，B 是固定框架镜。
将 B 在 A 上镜像展开：
    b' = b − 2·nA·[nA·(b − aA)]
    nB' = nB − 2·nA·(nA·nB)
折返等效光程 ℓF(q) = |nB' · (b' − s)|

xᵢ、yᵢ = ℓD(q) − ℓD(0)
dᵢ = [ℓD,ref(q) − ℓF(q)] − [ℓD,ref(0) − ℓF(0)]
```

沿展开光路与 A 求交，再把虚拟固定镜命中点折回 B，即可检查各反射点是否落在真实镜面口径内。令上述计算为 `f(q)`。先以 `q₀ = J₀ \ m` 为初值，再按 `q ← q + J(q) \ [m−f(q)]` 迭代，其中 `J(q)` 是 `f` 的 Jacobian，反斜杠表示最小二乘解。本文用中心差分求 `J(q)`。若旋转已知，X/Y 平均读数也可直接解二维线性方程。令 `nX=R·eX`、`nY=R·eY`、`Sx,Sy` 为各上层光头的中点，则 `mx1=nX·(Δ−Sx)+Sxₓ`，`my1=nY·(Δ−Sy)+Syᵧ`，并有精确差分 `mx2/(4cx)=nXᵧ`、`my2/(4cy)=−nYₓ`。

## v1 原式逐项核对

同一项先列《ifm模型.docx》第 1、4–5 页在 [原始模型 v1](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md) 中的公式，再列当前布局的修正版。**粗体标记新公式中改变的项或求解方法。** 新式的光程正号、基准、转序和角度单位见 [坐标与观测量](#坐标与观测量)。`nX、nY、Sx、Sy、d1(q)、d2(q)` 沿用 [有限姿态定义](#有限姿态的正向计算和反解)。


### X 解算对比

**旧公式 · v1**

```text
X = sfx * (mx1
    + [(X + Kx - kx/2)/2] * [(Ry - Ryix0)^2 + (Rz - Rzix0)^2]
    + Kx * (Ry^2 + Rz^2)/2
    - ee * (Rz + Rx*Ry)
    - ax*Ry)
```

**新公式 · v2**

- 名义一阶 `ΔX = mx1` **`+ ax·Ry`**。
- 有限姿态与 Y 联立，**`nXₓ·ΔX + nXᵧ·ΔY = mx1 − Sxₓ + nX·Sx − nX_z·ΔZ`**。
- **改动**　当 `ax` 按图取正高度差，Abbe 项由减改加。有限姿态用镜面实际法向和光头位置计算余弦及串扰。带符号的机台字段 `ax` 须先转换。

### Y 解算对比

**旧公式 · v1**

```text
Y = sfy * (my1
    + [(Y - Ly + ly/2)/2] * [(Rx - Rxiy0)^2 + (Rz - Rziy0)^2]
    - Ly * (Ry^2 + Rz^2)/2
    + dd * (Rz + Rx*Ry)
    + ay*Ry
    - sxy*X)
```

**新公式 · v2**

- 名义一阶 `ΔY = my1` **`− ay·Rx`**。
- 有限姿态与 X 联立，**`nYₓ·ΔX + nYᵧ·ΔY = my1 − Syᵧ + nY·Sy − nY_z·ΔZ`**。
- **改动**　Abbe 项由 `+ay·Ry` 改为 `−ay·Rx`。理想 Y 面法向的二阶余弦取 **`Rx² + Rz²`**。有限姿态用实际法向替代旧展开。

### Rzx 解算对比

**旧公式 · v1**

```text
Rzx = mx2/(4*cx) - Rx*Ry
      - (Xb/4*cx) * [(Ry - Ryix0)*dRyixh + (Rz - Rzix0)*dRzixh]
      + ux*Ry
```

**新公式 · v2**

- 名义一阶 `Rzx = mx2/(4cx)`。在 v2 转序下，二阶保留 `Rzx ≈ mx2/(4cx) − Rx·Ry`。
- 有限姿态取 **`A=cos(Ry)，B=sin(Rx)·sin(Ry)，Rzx=asin[(mx2/(4cx))/√(A²+B²)] − atan2(B,A)`**，取零位附近的反正弦分支。
- **改动**　明确差分为 `x1−x2`，束间距不变。用法向的精确反解替代无法从当前 CAD 标定的束线项。若 `Xb` 是长度，旧展开中的比例须写成 **`Xb/(4cx)`** 才无量纲。

### Rzy 解算对比

**旧公式 · v1**

```text
Rzy = my2/(4*cy)
      - (Yb/4*cy) * [(Rx - Rxiy0)*dRxiyh + (Rz - Rziy0)*dRziyh]
      + wy*Rx
```

**新公式 · v2**

- 名义一阶 `Rzy = my2/(4cy)`。
- 有限姿态 **`Rzy = asin[(my2/(4cy))/cos(Rx)]`**，取零位附近的分支。
- **改动**　明确差分为 `y2−y1`，束间距不变。按 v2 转序从实际法向反解。若 `Yb` 是长度，旧展开中的比例须写成 **`Yb/(4cy)`**。

### Z 解算对比

**旧公式 · v1**

```text
Z = sfz * (mz1 + X*Rx*Rz
    + szya*Y + szxa*X
    + ezxa*Rx + ezya*Ry + ezza*Rz
    + czxya*X*Ry + czxza*X*Rz + czyya*Y*Ry + czxxa*X*Rx
    + dzyya*Ry^2 + dzzza*Rz^2 + dzxxa*Rx^2 + dzxza*Rx*Rz)
```

**新公式 · v2**

- 名义一阶 `ΔZ = mz1` **`+ 50·Rx`**。
- 有限姿态由 **`mz1=[d1(q)+d2(q)]/2`** 和其余光程联合反解。隔离 `ΔX·Rx·Rz` 时，`mz1` 已含这一正项，反解取 **`−ΔX·Rx·Rz`**。
- **改动**　用当前 CAD 的横向采样位置确定 Rx 补偿，修正显式混合项方向，并用折返光路计算合成其他姿态效应。

### Ryz 解算对比

**旧公式 · v1**

```text
Ryz = sfryz * (mz2 * ((1 - 2*Z/kze)/kze)^2
      + (2/kze)*X*Rx^2 + (4/kze)*X*Ry^2
      + srxa*X + srya*Y + srza*Z
      + erxa*Rx + erza*Rz
      + crxxa*X*Rx + crxya*X*Ry + crxza*X*Rz
      + drxxa*Rx^2 + drxza*Rx*Rz + dryya*Ry)
```

**新公式 · v2**

- 纯高度偏置附近 `Ryz ≈` **`mz2/(554 mm + 2·ΔZ)`**。
- 有限姿态使用 **`mz2=d1(q)−d2(q)`**，按 [Z 标量方程](#从-z-差分单独求-ryz)求 `Ryz`。隔离测试中，差分已包含 **`+ΔX·Rx²`**、**`+3ΔX·Ry²`**，反解时扣除其贡献。
- **改动**　用带高度依赖的 CAD 灵敏度除差分长度，替代原式的倒长度平方因子。按 v1 对 `mz2` 的长度定义，平方项与同括号内的 `(X/kze)·角度²` 量纲不一致。

**转序检验。** 真 `Rz=0` 且 `Rx=Ry=1 mrad` 时，`RotZ·RotX·RotY` 的 X/Y 原始差分估计约为 `+1/0 µrad`，扣除当前 X 二阶项后两者约为零。换成 `RotZ·RotY·RotX`，同样的原始估计约为 `0/−1 µrad`，所以二阶项须与转序一起指定。

机台的尺度、非正交、镜面误差角及面形标定项按目标机数据定义。原式的 `dd/ee` 说明及其他字段差异见 [原始模型 v1 实现边界](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#原件差异与实现边界)。

## FreeCAD 六自由度验证

### 实际设置和读取流程

1. 在 **FreeCAD 0.21.2 原生 Python 环境**中读取《ws-ifm-agent.FCStd》，另存本地测试副本。用 `Moving_WS.Placement` 按表逐次设置 XYZ 平移及 Rx/Ry/Rz。每组 `recompute()` 后用 `getGlobalPlacement()` 核对镜块和晶圆实际变换，固定条镜保持在原位置。
2. 用当前位姿下的 FreeCAD 镜面和法向逐段求交、反射。每条直返路径为 `头 → 移动镜面 → 头`，每条折返为 `头 → 斜面 → 固定条镜 → 斜面 → 头`。逐个用 `Face.isInside` 检查命中点，从各 IFM 路径对象的 **`Shape.Length`** 读取往返长度。20 组共读取 **200 条**往返路径，全部命中有限镜面，最大返头几何闭合差 `6.82e-13 mm`。
3. 以 N00 为零位，先从每条读数扣零，再按 v2 规则除以 2，并把 Z 的直返、折返相减。独立数值程序只以这八路增量和名义 CAD 几何反解六自由度，解出后才与预设值比较。同时记录一阶反解误差。
4. 保存现场 C07 后关闭并重开本机测试副本，核对保存的 WS 位姿及十个光路实体长度，读取长度与保存前一致。测试副本位于 `D:/work/ME2/work/ws-ifm-freecad-pose-v1/WS-IFM六自由度验证_v1.FCStd`，光路和反解记录在同目录的 `freecad_paths_v1.json`、`freecad_pose_comparison_v1.json`。原 FCStd 文件的 SHA-256 复查一致。

本测试使用固定光头位置、有限理想平面镜和回到同一光头的驻值光路。FreeCAD 提供实际镜面及路径长度，光路按镜面反射条件构建。结果验证的是 v2 对当前 CAD 几何的解算，实机发射与接收约束、干涉相位及环境折射率见 [实机数据对接](#实机数据对接)。

| `ΔX=±1 mm`，角度步长依次 `2、1、0.5 mrad` | 混合差分趋于 `∂³mz1/∂X∂Rx∂Rz=+1`，`mz2` 的 `X·Rx²`、`X·Ry²` 系数趋于 `+1、+3`。 |
| 192 组组合位姿 | 均匀采样范围 `ΔX,ΔY∈±0.10 mm`、`ΔZ∈±0.05 mm`、各转角 `±100 µrad`。一阶近似最大光程差 `20.72 nm`，均方根 `4.43 nm`。用一阶线性矩阵反解，最大平移误差 `16.18 nm`，最大转角误差 `23.14 nrad`。 |
| 同一批样本的有限姿态反解 | 以一阶解为初值，做三次 Gauss–Newton 更新。最大光程闭合差小于 `10⁻⁶ nm`，位姿恢复误差小于 `10⁻⁶ nm`（平移）及 `2×10⁻⁶ nrad`（转角），处于本算例的数值舍入量级。 |

这些误差来自同一理想几何模型中的合成数据。复算时，零位等效直返光程 X 三束均 `280 mm`、Y 三束均 `235 mm`，两路 Z 折返 `595 mm`、直返 `290 mm`，各路直返减折返名义量为 `−305 mm`，计算增量时先扣除。数值复算脚本在本机 `work/ws-ifm-formula-validation-v1/verify_ifm_formula_v1.m`，随机种子 `20261121`（twister）。

## 实机数据对接
