## 验证结论

**v1 原式不能按字面直接用于当前 FreeCAD 布局。** Y 的一阶 Abbe 补偿轴应为 Rx。按本报告的右手坐标和光程正号，X/Y 的平移补偿分别是 `+ax·Ry` 和 `−ay·Rx`，Z 差分对 Ry 的灵敏度随高度按 `K_geo(Z)=K_geo0+2·Z` 变化。当前 CAD 的零位值见 [几何参数表](#几何参数表)。v2 给出经过 FreeCAD 位姿与光路实体验证的[八路逐项解算](#八路读数的逐项解算)，保留一阶近似和有限姿态联合反解作对照。原附件的公式、字段和待核对项见 [原始模型 v1](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md)。

Y 的转轴错误可用单轴反例直接判定。在其他量为零时，施加 `Ry = +100 µrad`，理想 Y 双束平均光程增量为零，原式 `+ay·Ry` 按 CAD 中的正值高度差会凭空产生 **3.25 µm** 一阶 Y 修正。反过来，施加 `Rx = +100 µrad` 会产生约 **+3.248 µm** 的 Y 平均光程变化。

## 坐标与观测量

![WS-IFM v5 几何光路示意，标出三束分布和基准](../images/WS-IFM-CAD%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E5%9B%BE_v5.svg)

- 以 CAD 晶圆上表面中心 O 为台体原点和转心，使用右手坐标。位姿向量 `q=(ΔX,ΔY,ΔZ,Rx,Ry,Rz)`，平移用 mm，转角用 rad。二阶和有限姿态采用主动旋转 `R=RotZ(Rz)·RotX(Rx)·RotY(Ry)`，即先施加 Y 旋转，再施加 X，最后施加 Z。若改用 AA 实际焦点作转心，应把各点坐标和位姿变换到同一基准。本 CAD 的 AA 焦点和 O 同高。
- 六路直接读数 `x1…x3、y1…y3` 取已经去除名义值的 **往返几何光程变化的一半**，光程变长为正。各路 Z 读数 `di` 取同一归一化下的 **直返增量减折返增量**。纯升高时两路 `di` 都增大。
- 本文令 `mx1=(x1+x2)/2`、`mx2=x1−x2`、`my1=(y1+y2)/2`、`my2=y2−y1`、`mz1=(d1+d2)/2`、`mz2=d1−d2`。上束对的正差均对应正 `Rz`，Z 正差对应正 `Ry`。部署到实机时需核对计数倍率、差分顺序和零位，见 [SWZS 流程](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#swzs)。

## 八路读数的逐项解算

本节把 X/Y 三束及两路 Z 差分直接换算为 **`X、Y、Z、Rx、Ryx、Ryz、Rzx、Rzy`**。其中 Ry 和 Rz 各有两个估计，对应六个独立位姿量。下列公式沿用 [坐标与观测量](#坐标与观测量) 的长度、正号和转序，`X、Y、Z` 指相对零位的 `ΔX、ΔY、ΔZ`。解算顺序为 **Y 面法向 → Rx、Rzy → X 面法向 → Ryx、Rzx → X、Y、Z → Ryz**。平移以 `Ryx` 和 `Rzy` 重建朝向，另外两项独立保留作对照。

### 从 X/Y 六束求四个角度读数

同组直接光束的差消去台体平移和镜面基准点。设 `n_X`、`n_Y` 为由各自三束恢复的单位法向，朝向取名义正分支。上束光头间距给出横向分量，下束相对上束中点的横向和高度偏置给出法向 Z 分量。参数见 [几何参数表](#几何参数表)。

```text
nY_x = −my2/B_Y
nY_z = (y3 − my1 + δx_Y·nY_x)/hy
nY_y = √(1 − nY_x² − nY_z²)

Rx  = asin(nY_z)
Rzy = atan2(−nY_x, nY_y)

nX_y = mx2/B_X
nX_z = (x3 − mx1 + δy_X·nX_y)/hx
nX_x = √(1 − nX_y² − nX_z²)

Ryx = asin(−nX_z/cos Rx)
Rzx = atan2(nX_y, nX_x) − atan2(sin Rx·sin Ryx, cos Ryx)
```

因为 X3 相对 X 上束中点的偏置是 `(0,δy_X,−hx)`，所以 `x3−mx1=−δy_X·nX_y+hx·nX_z`。Y 组同理。在所用转序下，`nY_z=sin Rx`、`nX_z=−cos Rx·sin Ryx`。X 面法向的 XY 方位为 `Rzx+atan2(sin Rx·sin Ryx,cos Ryx)`。输入需落在平方根和反三角函数的有效分支内。[查看四个角度的读数展开](#v1-原式逐项核对)

### 从三个平均读数求 X Y Z

用 `Rx、Ryx、Rzy` 构成 `R=RotZ(Rzy)·RotX(Rx)·RotY(Ryx)`。令 `p=R·eX、n=R·eY、w=R·eZ`，三者是用于重建平移的正交方向。这里采用 `Rzy` 作为 Rz 的输入。`Rzx` 继续作为冗余估计。设 `a=p_z`、`b=w_z`，对平移向量 `t=(X,Y,Z)`：

```text
C(t) = C_F + H_Z·p_x − w·(t−SF)
E(t) = p·(t−SF) − H_Z·w_x

M(t) = Z_F + C_F + H_Z·p_x + a·E(t) − b·C(t)
M0   = M(0)                    # 已求转角保持不变，平移取零
```

`M(t)` 是去除名义量 `L_Z0` 后的 Z 平均光程。它对平移的贡献为 `a·(p·t)+b·(w·t)`，所以可先用 X/Y 平均读数求前两个投影，再用 Z 平均读数求第三个投影。

```text
TP = mx1 + p·Sx − Sx_x
TN = my1 + n·Sy − Sy_y
TW = (mz1 − M0 − p_z·TP)/w_z

X = TP·p_x + TN·n_x + TW·w_x
Y = TP·p_y + TN·n_y + TW·w_y
Z = TN·n_z + mz1 − M0
```

最后一式由把 `TW` 代入 `TP·p_z+TN·n_z+TW·w_z` 得到，`TP·p_z` 正好相消。工作分支要求 `w_z≠0`。[查看 XYZ 的完整展开](#x-的完整展开)

### 从 Z 差分单独求 Ryz

令待解角为 `θ=Ryz`，固定已求得的 `t、Rx、Rzy`。定义

```text
k = cos Rx
e = (cos Rzy, sin Rzy, 0)
f = (sin Rzy·sin Rx, −cos Rzy·sin Rx, k)

p(θ) = e·cos θ − f·sin θ
w(θ) = e·sin θ + f·cos θ
```

将固定镜在移动折转镜面上展开。左路取 `σ=+1`，右路取 `σ=−1`。两路的等效半往返光程为

```text
ℓref,σ  = P0 + H_Z·p_x + σ·p·(t−SP)
ℓfold,σ = Z_B − Z_F − (σ·p_z−w_z)·[C(t)+σ·E(t)]
```

对 `ℓref,σ−ℓfold,σ` 求平均并扣除 `L_Z0`，得到上节的 `M(t)`。两路作差得到下式。

```text
CD = H_Z·k·f_x
A  = e·(t−SP)
B  = −f·(t−SP) − k·C_F
C  = −k·e·(t−SF)
E  = k·f·(t−SF)

mz2/2 = CD + A·cos θ + B·sin θ + C·cos(2θ) + E·sin(2θ)
```

令 `u=tan(θ/2)`、`F=CD−mz2/2`，得到

```text
(F−A+C)·u⁴ + (2B−4E)·u³ + (2F−6C)·u² + (2B+4E)·u + (F+A+C) = 0
Ryz = 2·atan(u)
```

若最高次系数为零，按实际次数求根。用 `±5 mrad` 检查原 20 组数据的近零分支，每组均有唯一实根，`∂mz2/∂θ` 在该分支内的保守下界为 `543.96 mm/rad`。根由工作分支选定，`Ryx` 不作为选根目标。[查看四次方程系数的完整展开](#ryz-解算对比)

## 修正后方程

### 名义位姿的一阶反解

台体上点 `p` 的一阶位移为 `v(p)=Δ+ω×p`，`ω=(Rx,Ry,Rz)`。X/Y 直接通道取位移在入射方向上的投影。Z 折返路的长度变化由移动折点的入射、折出方向之差决定，固定镜上的命中点沿镜面切向移动。设 `u₁=+eX`、`u₂=−eX`，有

```text
dᵢ = eZ·v(Fᵢ) + uᵢ·[v(Pᵢ)−v(Fᵢ)]

             X  Y  Z     Rx       Ry          Rz
x1           1  0  0      0      −ax         B_X/2
x2           1  0  0      0      −ax        −B_X/2
x3           1  0  0      0      −ax−hx     −δy_X
y1           0  1  0     ay        0        −B_Y/2
y2           0  1  0     ay        0         B_Y/2
y3           0  1  0     ay+hy     0         δx_Y
d1           0  0  1     Y_Z      K_geo0/2     0
d2           0  0  1     Y_Z     −K_geo0/2     0
```

表中各行的系数乘位姿向量得到 mm。名义一阶矩阵 `J₀` 的 XY 六路秩为 5，加入 Z 两路后秩为 6。分通道近似解如下。

```text
Rzx ≈ mx2/B_X
Rzy ≈ my2/B_Y
Rz  ≈ (Rzx + Rzy)/2             # 理想等权示例
Ryx ≈ (mx1 − x3 − δy_X·Rz)/hx
Rx  ≈ (y3 − my1 − δx_Y·Rz)/hy

X   ≈ mx1 + ax·Ryx
Y   ≈ my1 − ay·Rx
Z   ≈ mz1 − Y_Z·Rx
Ryz ≈ mz2/K_geo0
```

第三束的横向偏置产生 `Rz` 项，计算上下束差时须保留。要利用全部观测，可从 `J₀ q = (x1,x2,x3,y1,y2,y3,d1,d2)ᵀ` 求最小二乘位姿，实测权重按通道确定。

### Z 差分的高度修正

在零位，折点的 X 向间距为 `B_Z=−2·(C_F+Z_F)`，直返水平束比折返水平束高 `Z_P−Z_F`。故 Ry 的零位差分灵敏度由几何间距与两个通道的高度差共同决定。纯升高 Z 后，左右水平束与斜面的交点各向外移 Z。

```text
K_geo0 = B_Z + 2·(Z_P−Z_F) = 2·(Z_P−2·Z_F−C_F)
K_geo(Z) = K_geo0 + 2·Z

∂(d1−d2)/∂Ry = K_geo(Z)
Ryz ≈ mz2/K_geo(Z)               # 纯高度偏置附近的局部一阶式
```

在当前 CAD 参数下，`B_Z=465 mm`、`Z_P−Z_F=44.5 mm`，`K_geo0=554 mm/rad`。几何灵敏度与仪表的 `kze` 映射需按实际光程归一化确定。有横向平移或多角度变化时，使用[逐项解算的 Z 标量方程](#从-z-差分单独求-ryz)。

### 有限姿态的正向计算和反解

本节的联合迭代保留作交叉验证。当前布局可按[八路逐项解算](#八路读数的逐项解算)直接求出各量。

对移动平面上一点 `a` 和单位法向 `n`，按 `a(q)=R·a+Δ`、`n(q)=R·n` 更新。光头固定，记其 CAD 光路起点为 `s`。理想镜面下采用从同一光头出发并返回的驻值路径。

```text
直返等效光程 ℓD(q) = |n(q) · (a(q) − s)|

设 A 是变换后的移动折镜，B 是固定框架镜。
将 B 在 A 上镜像展开：
    b' = b − 2·nA·[nA·(b − aA)]
    nB' = nB − 2·nA·(nA·nB)
折返等效光程 ℓF(q) = |nB' · (b' − s)|

xᵢ、yᵢ = ℓD(q) − ℓD(0)
dᵢ = [ℓD,ref(q) − ℓF(q)] − [ℓD,ref(0) − ℓF(0)]
```

沿展开光路与 A 求交，再把虚拟固定镜命中点折回 B，即可检查各反射点是否落在真实镜面口径内。令上述计算为 `f(q)`。先以 `q₀ = J₀ \ m` 为初值，再按 `q ← q + J(q) \ [m−f(q)]` 迭代，其中 `J(q)` 是 `f` 的 Jacobian，反斜杠表示最小二乘解。本文用中心差分求 `J(q)`。若旋转已知，X/Y 平均读数也可直接解二维线性方程。令 `nX=R·eX`、`nY=R·eY`、`Sx,Sy` 为各上层光头的中点，则 `mx1=nX·(Δ−Sx)+Sxₓ`，`my1=nY·(Δ−Sy)+Syᵧ`，并有精确差分 `mx2/(4cx)=nXᵧ`、`my2/(4cy)=−nYₓ`。

## v1 原式逐项核对

先列 v1 的六条原式，再给出 v2 的完整符号展开。**粗体指出解算中的改动。** `Rx` 和 `Ryx` 在 v1 中没有单独列式。变量正号、单位和光头尺寸见 [坐标与观测量](#坐标与观测量) 和 [几何参数表](#几何参数表)。

[展开 X](#x-的完整展开) · [展开 Y](#y-解算对比) · [展开 Z](#z-解算对比) · [展开 Rx](#rx-解算对比) · [展开 Ryx](#ryx-解算对比) · [展开 Ryz](#ryz-解算对比) · [展开 Rzx](#rzx-解算对比) · [展开 Rzy](#rzy-解算对比)

平移式中的 `α=Rx`、`β=Ryx`、`γ=Rzy` 先由各束差值求出，`p、n、w` 是 `RotZ(γ)·RotX(α)·RotY(β)` 的列向量。用三角函数写成

```text
p_x = cos γ·cos β − sin γ·sin α·sin β
p_y = sin γ·cos β + cos γ·sin α·sin β
p_z = −cos α·sin β

n_x = −sin γ·cos α
n_y =  cos γ·cos α
n_z =  sin α

w_x = cos γ·sin β + sin γ·sin α·cos β
w_y = sin γ·sin β − cos γ·sin α·cos β
w_z = cos α·cos β
```

以下 X/Y/Z 展开式已代入三个投影及 Z 均值零平移项。角度以 rad 输入，长度参数、读数和位移使用同一长度单位。

### X 解算对比

**旧公式 · v1**

```text
X = sfx * (mx1
    + [(X + Kx - kx/2)/2] * [(Ry - Ryix0)^2 + (Rz - Rzix0)^2]
    + Kx * (Ry^2 + Rz^2)/2
    - ee * (Rz + Rx*Ry)
    - ax*Ry)
```

**新公式 · v2**

#### X 的完整展开

把 `TW=(mz1−M0−p_z·TP)/w_z` 代入，得到 `X=(p_x−p_z·w_x/w_z)·TP+n_x·TN+(w_x/w_z)·(mz1−M0)`。第一项系数可化简为 `cos γ/cos β`。**再代入光头参数及零平移项**，得

```text
X = (cos γ/cos β)·[mx1 + H_X·(1−p_x) − ax·p_z]
  + n_x·[my1 + H_Y·(1−n_y) − ay·n_z]
  + (w_x/w_z)·[
        mz1 − Z_F − C_F − H_Z·p_x
        + p_z·(Y_Z·p_y + Z_F·p_z + H_Z·w_x)
        + w_z·(C_F + H_Z·p_x + Y_Z·w_y + Z_F·w_z)
    ]
```

零位一阶补偿为 **`X≈mx1+ax·Ryx`**。长度参数 `ax` 用上束高度差的正值。

### Y 解算对比

**旧公式 · v1**

```text
Y = sfy * (my1
    + [(Y - Ly + ly/2)/2] * [(Rx - Rxiy0)^2 + (Rz - Rziy0)^2]
    - Ly * (Ry^2 + Rz^2)/2
    + dd * (Rz + Rx*Ry)
    + ay*Ry
    - sxy*X)
```

**新公式 · v2**

#### Y 的完整展开

代入 `TW` 后，X 组的系数为 `p_y−p_z·w_y/w_z=sin γ/cos β`。**Y 由三组均值直接重建**，

```text
Y = (sin γ/cos β)·[mx1 + H_X·(1−p_x) − ax·p_z]
  + n_y·[my1 + H_Y·(1−n_y) − ay·n_z]
  + (w_y/w_z)·[
        mz1 − Z_F − C_F − H_Z·p_x
        + p_z·(Y_Z·p_y + Z_F·p_z + H_Z·w_x)
        + w_z·(C_F + H_Z·p_x + Y_Z·w_y + Z_F·w_z)
    ]
```

零位一阶补偿为 **`Y≈my1−ay·Rx`**，原式的 `+ay·Ry` 改为对 Rx 补偿。Y 镜面在名义坐标下的二阶方向余弦使用 `Rx²+Rz²`。

### Rzx 解算对比

**旧公式 · v1**

```text
Rzx = mx2/(4*cx) - Rx*Ry
      - (Xb/4*cx) * [(Ry - Ryix0)*dRyixh + (Rz - Rzix0)*dRzixh]
      + ux*Ry
```

**新公式 · v2**

#### Rzx 的完整展开

由 X 组法向求 XY 方位角，再扣除由既定转序产生的附加角。**将法向和附加角都用读数展开**，

```text
Rzx = atan2(
          mx2/B_X,
          √(1−(mx2/B_X)²−[(x3−mx1+δy_X·mx2/B_X)/hx]²)
      )
      − atan2(
          −[(x3−mx1+δy_X·mx2/B_X)/hx]·[(y3−my1−δx_Y·my2/B_Y)/hy],
          √(1−[(x3−mx1+δy_X·mx2/B_X)/hx]²−[(y3−my1−δx_Y·my2/B_Y)/hy]²)
      )
```

第一项保留 v1 的 X 上束间距。第二项在零位附近的二阶近似是 `−Rx·Ryx`，其符号及分配取决于转序。

### Rzy 解算对比

**旧公式 · v1**

```text
Rzy = my2/(4*cy)
      - (Yb/4*cy) * [(Rx - Rxiy0)*dRxiyh + (Rz - Rziy0)*dRziyh]
      + wy*Rx
```

**新公式 · v2**

#### Rzy 的完整展开

**从 Y 三束直接恢复方位角**，

```text
Rzy = atan2(
          my2/B_Y,
          √(1−(my2/B_Y)²−[(y3−my1−δx_Y·my2/B_Y)/hy]²)
      )
```

在零位附近回到 `Rzy≈my2/B_Y`。

### Z 解算对比

**旧公式 · v1**

```text
Z = sfz * (mz1 + X*Rx*Rz
    + szya*Y + szxa*X
    + ezxa*Rx + ezya*Ry + ezza*Rz
    + czxya*X*Ry + czxza*X*Rz + czyya*Y*Ry + czxxa*X*Rx
    + dzyya*Ry^2 + dzzza*Rz^2 + dzxxa*Rx^2 + dzxza*Rx*Rz)
```

**新公式 · v2**

#### Z 的完整展开

代入 `TW` 后，`p_z·TP` 相消，得到 **`Z=n_z·TN+mz1−M0`**。代入 Y 均值投影和 Z 零平移项后，

```text
Z = n_z·[my1 + H_Y·(1−n_y) − ay·n_z]
  + mz1 − Z_F − C_F − H_Z·p_x
  + p_z·(Y_Z·p_y + Z_F·p_z + H_Z·w_x)
  + w_z·(C_F + H_Z·p_x + Y_Z·w_y + Z_F·w_z)
```

零位一阶为 **`Z≈mz1−Y_Z·Rx`**。隔离 `X·Rx·Rz` 时，从均值反解应扣去该几何贡献，完整展开式已包含这类耦合。

### Ryz 解算对比

**旧公式 · v1**

```text
Ryz = sfryz * (mz2 * ((1 - 2*Z/kze)/kze)^2
      + (2/kze)*X*Rx^2 + (4/kze)*X*Ry^2
      + srxa*X + srya*Y + srza*Z
      + erxa*Rx + erza*Rz
      + crxxa*X*Rx + crxya*X*Ry + crxza*X*Rz
      + drxxa*Rx^2 + drxza*Rx*Rz + dryya*Ry)
```

**新公式 · v2**

#### Ryz 的完整展开

用已求的 `X、Y、Z、α=Rx、γ=Rzy`，将四次方程系数全部展开成三角函数。**用一个 Z 差分标量方程反解 `Ryz`**，

```text
A = cos γ·X + sin γ·(Y−Y_Z)
B = −sin γ·sin α·X + cos γ·sin α·(Y−Y_Z)
    − cos α·(Z−Z_P) − cos α·C_F
C = −cos α·[cos γ·X + sin γ·(Y−Y_Z)]
E = cos α·[sin γ·sin α·X − cos γ·sin α·(Y−Y_Z) + cos α·(Z−Z_F)]
F = H_Z·cos α·sin γ·sin α − mz2/2

(F−A+C)·u⁴ + (2B−4E)·u³ + (2F−6C)·u² + (2B+4E)·u + (F+A+C) = 0
Ryz = 2·atan(u)
```

`u` 取 [工作分支内的实根](#从-z-差分单独求-ryz)。纯高度偏置附近的局部一阶式为 **`Ryz≈mz2/(K_geo0+2·Z)`**，原式的倒长度平方因子由实际差分灵敏度取代。

### Rx 解算对比

**旧公式 · v1**　文档将 `Rx` 用作其他方程的输入，未列独立解算式。

**新公式 · v2**

#### Rx 的完整展开

**`Rx = asin[(y3−my1−δx_Y·my2/B_Y)/hy]`**。先扣除 Y3 横向偏置带来的差值，再按上、下束高度差归一化。

### Ryx 解算对比

**旧公式 · v1**　文档说明 `Ryx` 由 X IFM 测得，未列独立解算式。

**新公式 · v2**

#### Ryx 的完整展开

**`Ryx = asin{−(x3−mx1+δy_X·mx2/B_X) / [hx·√(1−[(y3−my1−δx_Y·my2/B_Y)/hy]²)]}`**。分子含 X3 的横向偏置，根号来自 `cos Rx`，所有量可直接由 X/Y 六束读数计算。

在既定转序下，`Rzx` 的二阶修正与 v1 一致。另一转序会改变 X/Y 的混合项分配。若 `Xb、Yb` 是长度，v1 的束线修正比例应写成 `Xb/(4cx)`、`Yb/(4cy)`，才无量纲。机台尺度、非正交、镜面误差角和面形补偿见 [v1 字段差异](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#原件差异与实现边界)。

**复算结果。** 用 [原 20 组 FreeCAD 光程](#逐项解算的-20-组-freecad-验证) 重算八个量，与原数值逐项式的最大平移差为 `1.71×10⁻¹³ mm`，最大角差为 `6.90×10⁻¹⁷ rad`。另以改变束间距、光头位置和折镜位置的一组同拓扑理想几何作前向模拟，得到最大平移残差 `2.33×10⁻¹³ mm`、最大角残差 `7.16×10⁻¹⁶ rad`。这些残差处于数值舍入量级。

## 数值验证

在此前的几何与 MATLAB 交叉复核中，用 **FreeCAD 0.21** 原生重新打开本机《ws-ifm-agent.FCStd》，核对镜块、条形镜、晶圆、坐标轴和光路共 17 个对象的顶点，以及两路上折对固定镜下表面的命中。读取后关闭文件，源文件 SHA-256 复查一致。MATLAB R2024b 用镜像展开求理想往返光程，逐点检查反射点在有限镜面口径内。名义 Jacobian 用 `1e−3 mm`、`1e−5 rad` 的中心差分，解析与数值的最大系数差为 `2.30×10⁻⁸`（相应列单位）。

| 独立检查 | 结果 |
| --- | --- |
| 各轴分别平移 `+0.100 mm`，无转角 | X 仅响应 X 三束，Y 仅响应 Y 三束，Z 仅响应两路 Z。各响应均为 `+0.100 mm`。 |
| 单轴转动 `+100 µrad` | `Ry` 产生 X 上束平均 `−4.352 µm`、Y 上束平均为零。 `Rx` 产生 Y 上束平均 `+3.248 µm`、Z 均值 `−5.000 µm`。 |
| `ΔZ = −5, −1, 0, +1, +5 mm` 时对 Ry 做中心差分 | Z 差分灵敏度为 `544、552、554、556、564 mm/rad`，与 `554+2ΔZ` 一致。 |
| `ΔX=±1 mm`，角度步长依次 `2、1、0.5 mrad` | 混合差分趋于 `∂³mz1/∂X∂Rx∂Rz=+1`，`mz2` 的 `X·Rx²`、`X·Ry²` 系数趋于 `+1、+3`。 |
| 192 组组合位姿 | 均匀采样范围 `ΔX,ΔY∈±0.10 mm`、`ΔZ∈±0.05 mm`、各转角 `±100 µrad`。一阶近似最大光程差 `20.72 nm`，均方根 `4.43 nm`。用一阶线性矩阵反解，最大平移误差 `16.18 nm`，最大转角误差 `23.14 nrad`。 |
| 同一批样本的有限姿态反解 | 以一阶解为初值，做三次 Gauss–Newton 更新。最大光程闭合差小于 `10⁻⁶ nm`，位姿恢复误差小于 `10⁻⁶ nm`（平移）及 `2×10⁻⁶ nrad`（转角），处于本算例的数值舍入量级。 |

这些误差来自同一理想几何模型中的合成数据。复算时，零位等效直返光程 X 三束均 `280 mm`、Y 三束均 `235 mm`，两路 Z 折返 `595 mm`、直返 `290 mm`，各路直返减折返名义量为 `−305 mm`，计算增量时先扣除。数值复算脚本在本机 `work/ws-ifm-formula-validation-v1/verify_ifm_formula_v1.m`，随机种子 `20261121`（twister）。

## 实机数据对接
