## 验证结论

对同一批 20 组 FreeCAD 光程，v1 原式与 v2 修正式的最大平移误差分别为 **72.988 µm** 和 **0.469 nm**。v2 的冗余 Ry 估计 Ryz 最大误差为 **0.932 nrad**。逐组列出预设位姿、两版解算值和有符号误差。v1 缺失的 Rx、Ryx 采用同组读数解补足。 [逐组结果](#逐项解算的-20-组-freecad-验证)

## 坐标与观测量

![WS-IFM v5 几何光路示意，标出三束分布和基准](../images/WS-IFM-CAD%E6%95%B0%E5%AD%A6%E6%A8%A1%E5%9E%8B%E5%9B%BE_v5.svg)

- 以 CAD 晶圆上表面中心 O 为台体原点和转心，使用右手坐标。位姿向量 `q=(ΔX,ΔY,ΔZ,Rx,Ry,Rz)`，平移用 mm，转角用 rad。采用主动旋转 `R=RotZ(Rz)·RotX(Rx)·RotY(Ry)`，即先施加 Y 旋转，再施加 X，最后施加 Z。若改用 AA 实际焦点作转心，应把各点坐标和位姿变换到同一基准。本 CAD 的 AA 焦点和 O 同高。
- 六路直接读数 `x1…x3、y1…y3` 取已经去除名义值的 **往返几何光程变化的一半**，光程变长为正。各路 Z 读数 `di` 取同一归一化下的 **直返增量减折返增量**。纯升高时两路 `di` 都增大。
- 本文令 `mx1=(x1+x2)/2`、`mx2=x1−x2`、`my1=(y1+y2)/2`、`my2=y2−y1`、`mz1=(d1+d2)/2`、`mz2=d1−d2`。上束对的正差均对应正 `Rz`，Z 正差对应正 `Ry`。部署到实机时需核对计数倍率、差分顺序和零位，见 [SWZS 流程](TWINSCAN%E6%B5%8B%E6%A0%A1%E9%A1%B9%E7%9B%AE%E6%B8%85%E5%8D%95_v2.md#swzs)。

### v1 字段怎么代入

| v1 字段 | v1 的定义与 v2 中的处理 |
| --- | --- |
| `mx1、mx2、my1、my2、mz1、mz2` | 保留平均值和差值的物理含义。按本文 [坐标与观测量](#坐标与观测量) 转换为扣零后的等效单程 mm，并明确 `mx2=x1−x2`、`my2=y2−y1`、`mz2=d1−d2`。 |
| `ax、ay、cx、cy` | 上束到焦面高度的正值和上束四分之一间距。公式直接用 `ax、ay、4cx、4cy`。`ay` 对应 `Rx`，见《ifm模型.docx》第 2 页。 |
| `Kx、Ly` | v1 为后角锥到工位参考点的水平距离，M 侧参考 ATHENA、E 侧参考镜头中心。v2 光程使用 CAD 等效光头和 O。须按下式做带符号的端点转换。 |
| `kx、ly` | 保留台体 X 尺寸及 Y 镜面到 O 的距离两倍的定义。扣零后的直接光程只依赖光头到 O 的轴向坐标。若从零阶光程换算，Y 距离为该光程加 `ly/2`。X 只有在 X 反射面关于 O 对称且间距等于 `kx` 时，才可在零阶光程上加 `kx/2`。当前 CAD X 反射面到 O 为 200 mm，镜块外包络 X 尺寸为 530 mm。 |
| `ee、dd` | 按《12-TT-L3-L3-ME_book.pdf》文件第 92 页（印刷第 84 页）表 2.2，采用 X-IFM 的 Y 向偏置 `ee` 和 Y-IFM 的 X 向偏置 `dd`。相对 O 定义为光头坐标减 O 坐标，机台字段按实际零点和方向换算。现 CAD 两个偏置为零。《ifm模型.docx》第 3 页牵涉两轴的文字和 Effect 栏有交叉，不能同时按其字面使用。 |
| `kze` | 沿用 v1 的 Z 双路有效臂含义。在本文读数约定下取 `kze=∂mz2/∂Ry` 的零位值。机器实际使用的 `kze` 需对照通道倍率。 |
| `ezxa、dzxxa、dzyya、drxza` | 保留 v1 的 Z 对 Rx、Z 对 Rx²、Z 对 Ry²、Ryz 对 Rx·Rz 的系数角色。下文给出在本理想几何下的值。实机报告中的这些字段可同时包含标定补偿。 |
| `sfx、sfy、sfz、sfryz、sxy` | 保留尺度和非正交的机台定义。以下几何复算使用已归一化长度，对应理想尺度为 1、非正交修正为 0。实际值按各机台的归零、单位及补偿接口使用。 |
| `Ryix0、Rzix0、Rxiy0、Rziy0、dRyixh、dRzixh、dRxiyh、dRziyh、ux、wy` | 这是束线误差角及失配，名义平行光路验证取理想值。若 `Xb、Yb` 表示长度，v1 比例项应写 `Xb/(4cx)、Yb/(4cy)`。原件未定义两个距离端点，当前 CAD 无法确认该束线补偿的完整表达。 |
| 其余 Z / Ryz 标定字段 | `szxa、szya` 等位置误差、姿态混合项和面形拟合系数保留在 [原始模型 v1](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#z-ifm-原式) 中，需适用机型的测量结果才能确定。 |

令 `B` 为 v1 后角锥、`R0` 为 v1 工位参考点、`S` 为 CAD 对应的等效光头。按本文轴向正号，若 `Kx=x_R0−x_B`、`Ly=y_R0−y_B`，转换为

```text
ΔKx = (x_B − x_S) + (x_O − x_R0)
ΔLy = (y_B − y_S) + (y_O − y_R0)

Kx+ΔKx = x_O−x_S
Ly+ΔLy = y_O−y_S
```

两端基准重合时对应的修正为零。当前 CAD 只给出两个等效轴向距离，分别为 480 mm 和 425 mm，因此复算用 `Kx+ΔKx`、`Ly+ΔLy` 的合量。机台两端坐标还没有在 CAD 中单独定义。

## 八路读数的逐项解算

先由 Y 三束求 [Rx](#rx-解算对比) 和 [Rzy](#rzy-解算对比)，再由 X 三束求 [Ryx](#ryx-解算对比) 和 [Rzx](#rzx-解算对比)。计算 [X](#x-解算对比)、[Y](#y-解算对比)、[Z](#z-解算对比) 时取 `Ry=Ryx`、`Rz=Rzy`。最后用 Z 差分求 [Ryz](#ryz-解算对比)，保留两组冗余差用于核对。

## 按 v1 符号修正的 v2 公式

### v1 原式逐项核对

左栏为 [v1 原式](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md)。右栏为当前读数和转序约定下的修正式，**粗体**标记修改或补充的项。XYZ 与 Ryz 采用转角二阶式。每个表下解释修改原因和新增符号。

[查看 X](#x-解算对比) · [Y](#y-解算对比) · [Z](#z-解算对比) · [Rx](#rx-解算对比) · [Ryx](#ryx-解算对比) · [Ryz](#ryz-解算对比) · [Rzx](#rzx-解算对比) · [Rzy](#rzy-解算对比)

#### X 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>X = sfx * (mx1</code><br><code>    + [(X + Kx - kx/2)/2] * [(Ry - Ryix0)^2 + (Rz - Rzix0)^2]</code><br><code>    + Kx * (Ry^2 + Rz^2)/2</code><br><code>    - ee * (Rz + Rx*Ry)</code><br><code>    - ax*Ry)</code> | <code>X ≈ mx1·[1+(Ry²−Rz²)/2] <strong>− my1·Rz + mz1·(Ry+Rx·Rz)</strong></code><br><code>   + (<strong>Kx+ΔKx</strong>)·(Ry²+Rz²)/2 <strong>+ ax·Ry</strong> <strong>+ ee·(Rz+Rx·Ry)</strong></code><br><code>   + dd·Rz² + ay·Rx·Rz + ezxa·Rx·Ry</code> |

**修改与原因**

- `−ax·Ry` 改为 **`+ax·Ry`**。正 `Ry` 会让位于原点下方的 X 上束读数变短，反解应补回这段光程。
- 用 **`(Kx+ΔKx)·(Ry²+Rz²)/2`** 和 `mx1` 的二阶系数计算名义方向余弦。原式中的光头距离项先按其端点换算，束线误差角对应的机台补偿单独标定。
- 按本文有向偏置的定义，`−ee·(Rz+Rx·Ry)` 改为 **`+ee·(Rz+Rx·Ry)`**。Y、Z 平均读数及 `dd、ay、ezxa` 产生的各项来自旋转后的三轴投影。

**符号含义**　`ΔKx` 是从 v1 的后角锥和工位参考点换算到等效头与 O 的**有向 X 距离修正**。`my1、mz1` 是 Y、Z 通道均值，`dd` 是 Y-IFM 的 X 向偏置，`ay` 是 Y Abbe 臂，`ezxa` 是 Z 的 Rx 补偿系数。这几项在 v1 已有定义，此处因交叉投影进入 X 式。

#### Y 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>Y = sfy * (my1</code><br><code>    + [(Y - Ly + ly/2)/2] * [(Rx - Rxiy0)^2 + (Rz - Rziy0)^2]</code><br><code>    - Ly * (Ry^2 + Rz^2)/2</code><br><code>    + dd * (Rz + Rx*Ry)</code><br><code>    + ay*Ry</code><br><code>    - sxy*X)</code> | <code>Y ≈ my1·[1−(<strong>Rx²+Rz²</strong>)/2] <strong>+ mx1·Rz + mz1·(−Rx+Ry·Rz)</strong></code><br><code>   + (<strong>Ly+ΔLy</strong>)·(<strong>Rx²+Rz²</strong>)/2 <strong>− ay·Rx</strong> <strong>− dd·Rz</strong></code><br><code>   + ee·Rz² + ax·Ry·Rz − ezxa·Rx²</code> |

**修改与原因**

- `+ay·Ry` 改为 **`−ay·Rx`**。绕 X 转动会改变下方 Y 上束的光程，纯绕 Y 转动保持理想 Y 镜面法向。
- Y 镜面方向余弦中的 `Ry²+Rz²` 改为 **`Rx²+Rz²`**。轴向距离使用换算后的 `Ly+ΔLy`。
- 按本文的 `dd` 正号和转序，原偏置项改为 **`−dd·Rz`**。`mx1、mz1` 及其余交叉项来自 X/Z 光程投影到 Y。

**符号含义**　`ΔLy` 是从 v1 的后角锥和工位参考点换算到等效头与 O 的**有向 Y 距离修正**。`mx1、mz1` 是 X、Z 通道均值，`ee` 是 X-IFM 的 Y 向偏置，`ax` 是 X Abbe 臂，`ezxa` 是 Z 的 Rx 补偿系数。

#### Z 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>Z = sfz * (mz1 + X*Rx*Rz</code><br><code>    + szya*Y + szxa*X</code><br><code>    + ezxa*Rx + ezya*Ry + ezza*Rz</code><br><code>    + czxya*X*Ry + czxza*X*Rz + czyya*Y*Ry + czxxa*X*Rx</code><br><code>    + dzyya*Ry^2 + dzzza*Rz^2 + dzxxa*Rx^2 + dzxza*Rx*Rz)</code> | <code>Z ≈ mz1 + <strong>(my1+ezxa)·Rx</strong> + <strong>(dzxxa−ay)·Rx²</strong></code><br><code>   + dzyya·Ry² <strong>− dd·Rx·Rz</strong></code> |

**修改与原因**

- 把 Rx 贡献写成 **`(my1+ezxa)·Rx`**。`ezxa` 保留原系数角色，`my1·Rx` 补偿随 Y 读数变化的几何投影。
- 原来的显式 `+X·Rx·Rz` 改入上述投影。按实际 XYZ 展开时，Z 反解需扣除 `X·Rx·Rz`；把 Y 位移换成 Y 平均读数后，该贡献已包含在 `my1·Rx` 中。
- 二阶项使用 **`(dzxxa−ay)·Rx² + dzyya·Ry² − dd·Rx·Rz`**。`dzxxa、dzyya` 是当前理想 Z 几何的系数，`−ay` 和 `−dd` 是将 Y 通道的焦高和横向偏置随 Rx 投影到 Z 时产生的项。

**符号含义**　本式沿用 v1 已定义的量。新进入 Z 式的 `my1` 是 Y 上束均值，`ay` 是 Y Abbe 臂，`dd` 是 Y-IFM 的 X 向偏置。

#### Rx 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| v1 未列 `Rx` 的独立公式。 | <code>nY_z = [y3−my1−δx_Y·my2/(4cy)]/hy</code><br><code>Rx  = <strong>asin(nY_z)</strong></code> |

**修改与原因**

- 补全 **`Rx=asin(nY_z)`**。Y 镜面法向在所定转序下的 Z 分量等于 `sin Rx`，由 Y3 和上束差恢复。

**符号含义**　`nY_z` 是 Y 镜面单位法向的 Z 分量；`hy` 是 Y3 至上束的正值高度差，`δx_Y` 是 Y3 相对上束中点的 X 向有符号偏置。

#### Ryx 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| v1 未列 `Ryx` 的独立公式。 | <code>nX_z = [x3−mx1+δy_X·mx2/(4cx)]/hx</code><br><code>nY_z = [y3−my1−δx_Y·my2/(4cy)]/hy</code><br><code>Ryx = <strong>asin(−nX_z/√[1−nY_z²])</strong></code> |

**修改与原因**

- 补全 **`Ryx=asin(−nX_z/√[1−nY_z²])`**。在约定转序下 `nX_z=−cos Rx·sin Ryx`，所以换算时要除以 `cos Rx`。

**符号含义**　`nX_z、nY_z` 是 X、Y 镜面单位法向的 Z 分量；`hx、hy` 为两组上下束高差，`δy_X、δx_Y` 为第三束在各自横向相对上束中点的有符号偏置。

#### Ryz 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>Ryz = sfryz * (mz2 * ((1 - 2*Z/kze)/kze)^2</code><br><code>      + (2/kze)*X*Rx^2 + (4/kze)*X*Ry^2</code><br><code>      + srxa*X + srya*Y + srza*Z</code><br><code>      + erxa*Rx + erza*Rz</code><br><code>      + crxxa*X*Rx + crxya*X*Ry + crxza*X*Rz</code><br><code>      + drxxa*Rx^2 + drxza*Rx*Rz + dryya*Ry)</code> | <code>A = 3·X</code><br><code>B = <strong>kze + 2·Z − 2·(Y+ezxa)·Rx</strong></code><br><code>C = X·Rx² − kze·drxza·Rx·Rz − mz2</code><br><code></code><br><code>Ryz ≈ <strong>−2·C / [B + √(B²−4·A·C)]</strong></code> |

**修改与原因**

- 平方分母改为 **由 Z 差分反解转角**。纯高度偏置附近，一阶灵敏度是 `kze+2·Z`，所以 `Ryz≈mz2/(kze+2·Z)`。按本文读数单位，旧平方分母使主项产生倒长度量纲。
- 以 **`X·Rx² + 3·X·θ² − kze·drxza·Rx·Rz`** 表达差分中的横向平移与转角几何项，按近零根反解。`drxza` 沿用 v1 的 Rx·Rz 修正系数角色，理想值由 CAD 几何得到。

**符号含义**　`θ` 是待解的 `Ryz`。`A` 是差分对 θ² 的系数，`B` 是当前 Z/Y/Rx 条件下对 θ 的一阶灵敏度，`C` 是 θ 为零时的预测差分减实测 `mz2`。三者是求根时的中间系数。取 B>0、B²−4AC≥0 对应的近零分支；A=0 时退化为 −C/B。

#### Rzx 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>Rzx = mx2/(4*cx) - Rx*Ry</code><br><code>      - (Xb/4*cx) * [(Ry - Ryix0)*dRyixh + (Rz - Rzix0)*dRzixh]</code><br><code>      + ux*Ry</code> | <code>nX_z = [x3−mx1+δy_X·mx2/(4cx)]/hx</code><br><code>nY_z = [y3−my1−δx_Y·my2/(4cy)]/hy</code><br><code>Rzx = atan2(mx2/(4cx), √[1−(mx2/(4cx))²−nX_z²])</code><br><code>    <strong>− atan2(−nX_z·nY_z, √[1−nX_z²−nY_z²])</strong></code> |

**修改与原因**

- 保留 **`mx2/(4cx)`** 对应的上层束间距，用 X 三束读数恢复 X 镜面法向，再用 `atan2` 计算法向方位。
- 用 **`−atan2(−nX_z·nY_z, √[1−nX_z²−nY_z²])`** 去除既定转序的角度贡献。展开至二阶，仍是原式的 `−Rx·Ry`。
- 当前理想平行光路采用零失配。若 `Xb` 为长度，旧束线补偿比例的括号应为 `Xb/(4cx)`，这样量纲才成立。

**符号含义**　`nX_z、nY_z` 是 X、Y 镜面单位法向的 Z 分量。`hx、hy` 是下束至各自上束的正值高度差；`δy_X`、`δx_Y` 分别是 X3 的 Y 偏置和 Y3 的 X 偏置，按第三束光头坐标减各自上束中点坐标定义。

#### Rzy 解算对比

| 初始 v1 公式 | 按 v1 参数定义修正的公式 |
| --- | --- |
| <code>Rzy = my2/(4*cy)</code><br><code>      - (Yb/4*cy) * [(Rx - Rxiy0)*dRxiyh + (Rz - Rziy0)*dRziyh]</code><br><code>      + wy*Rx</code> | <code>nY_z = [y3−my1−δx_Y·my2/(4cy)]/hy</code><br><code>Rzy = <strong>atan2(my2/(4cy), √[1−(my2/(4cy))²−nY_z²])</strong></code> |

**修改与原因**

- 把 **`my2/(4cy)`** 作为法向横向分量的输入，再利用 Y3 求法向的 Z 分量，得到有限姿态下的 Y 方位角。零位一阶仍为 `my2/(4cy)`。
- 当前理想平行光路采用零失配。若 `Yb` 为长度，旧束线补偿比例的括号应为 `Yb/(4cy)`，这样量纲才成立。

**符号含义**　`nY_z` 是 Y 镜面单位法向的 Z 分量；`hy` 是 Y 上下束正值高度差，`δx_Y` 是 Y3 相对 Y 上束中点的 X 向有符号偏置。

## FreeCAD 六自由度验证

沿用 FreeCAD 0.21.2 保存的 20 组数据。每组用十条往返光程扣除 N00 零位，按 [坐标与观测量](#坐标与观测量) 生成**同一组八路读数**，分别代入 [v1 原式与 v2 修正式](#v1-原式逐项核对)。预设位姿只用于计算误差。

- **解算约定**　两版均取 `Ry=Ryx`、`Rz=Rzy`。v1 未给出独立的 Rx、Ryx，两列角度采用 [Rx](#rx-解算对比)、[Ryx](#ryx-解算对比) 右栏从同组读数得到的结果，作为 v1 原式的姿态输入。各版分别计算自己的 Rzy，并代入各自的平移式。v1 的 X、Y 按[原式代数重排](WS-IFM%E6%A8%A1%E5%9E%8B_v1.md#固定姿态时的-xy-代数解)求解，保留原符号和系数。
- **v1 参数代入**　用 CAD 等效光头对应 v1 后角锥、用 O 对应工位参考点，取 `Kx=480 mm`、`Ly=425 mm`，由 CAD 取 `kx=530 mm`、`ly=380 mm`。采用上文 [几何参数](#几何参数表) 的 `ax、ay、cx、cy、kze、ezxa、dzxxa、dzyya、drxza`。尺度 `sfx、sfy、sfz` 取 1，其余安装、失配和标定补偿项按理想几何取零。v1 的 Ryz 另以 `sfryz=1` 作数值对照，单位约定见[冗余角表](#冗余角对照)。
