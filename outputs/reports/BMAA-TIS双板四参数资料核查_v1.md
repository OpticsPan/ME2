## 每块板描述四参数，WS 与两块板怎样分开

| 层级、原文件及页码 | 已确认的物理量或约束 |
| --- | --- |
| L1《13_AP-L1-ME_rel_3.2.pdf》文件第 30–31、35 页；L3《04-TT-L3-ATS-AA-2v0.pdf》文件第 76–78 页（印刷 70–72），图 5.21、5.22 | 标记有已知的板内坐标。台移动时，AA 判断何时标记对准，XY IFM 给出台位置。TRM 有两个平移分量、一个面内转角及一个倍率。两台各以 TIS1 的名义平移规定本台的平移基准；图 5.22 中 WS 原点在台中央，TIS1 在右下。AA 找到 TIS1 时对照 IFM 实读和应读，差量用于更新测量侧 WS 的 X0、Y0。 |
| L1《13_AP-L1-ME_rel_3.2.pdf》文件第 38 页 | 早期 Chuck 2 的 **Coarse** 报表分别给每板列 Tx、Ty（mm）、Rz（µrad）、M（无量纲）。TIS1 平移旧／新同为 (−122.5000000, 144.5000000)，转角从 0 到 164.200，倍率从 1 到 0.9999991。TIS2 平移从 (144.3000000, −144.5000000) 变为 (144.2999652, −144.5000017)，转角从 0 到 −154.301，倍率从 1 到 0.9999966。可用来理解字段与基准，不作为 Fine 的实测记录。 |
| L3《TT-MA-ME_setupblock_1-5_1v3.ppt》第 33、40 张；L3《04-TT-L3-ATS-AA-2v0.pdf》文件第 122 页 | 自动流程细调 WS 零位和 TIS2 平移，并求载板的转角、倍率。有 ILIAS 或 Abbe/CSCM 的配置另有相应载板处理。本节只绘两块 TIS。BMAA Fine 明列的 WS 零位是测量侧 X0、Y0；没有在该输出清单发现一组独立写入的 WS 零位转角和倍率。 |
| L3《12-TT-L3-L3-ME_book.pdf》文件第 98 页（印刷 90）；L3《TT-MA-ME_setupblock_6-8_1v3.ppt》第 57–58 张 | 整机另有台坐标非正交／比例校准；改变台坐标后，已确定的板坐标需随之变换或复测。这解释了为何可以在一般模型中画 WS 的共同转角或标尺误差，却不能把它们都列为 BMAA 的独立输出。倍率描述长度换算，单纯一次刚体归零不会把 WS 放大或缩小。 |
| L3《05-TT-L3-TIS-2v0.pdf》文件第 7 页（印刷 1），图 1.1 | 本配置每个卡盘有两块 TIS。朝晶圆搬运侧观察，台面中心是 WS 坐标原点，TIS1 位于图右下，TIS2 位于左上，两板的斜边面向晶圆。 |

**制图依据。** 总图保留 L3 图 5.22 的观察方向，纸面向左为 WS 的正 X、向下为正 Y，正 Z 朝读者。板的位置关系及标记次序可用 L2 图 1.4、1.27 核对。板的名义轮廓与示例轮廓、共同转角、比例变化为几何解释；示意偏差、点距和姿态不能充当实机参数。
