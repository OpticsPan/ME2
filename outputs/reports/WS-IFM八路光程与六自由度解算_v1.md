# WS-IFM 从光程到六自由度解算 v1

[光程与可观测性](#measurement-observability) · [工业解算流程](#industrial-method) · [ME2 八路数据](#me2-channels) · [C0 右端的 Ry](#c0-ry-input) · [成果索引](../README.md)

一条可独立读出的 IFM 通道提供一个标量光程变化。多条光路的方向与落点不同，因此对刚体姿态的灵敏度不同。六自由度由多条光程约束共同确定。ME2 的 X/Y 共六路光程先提供 X、Y、Rx、Ry、Rz 五个自由度，Z 两路再补充高度并提供另一套 Ry 观测。读数超过六个时，冗余量可用于相互校验或融合。

<a name="measurement-observability"></a>

## 光程读数如何区分平移和转动

对理想的、已换算成位移的单测点直线观测，近零位时可写

```text
局部测点位移 = 平移 t + 旋转向量 ω × 位置向量 r_i
第 i 路读数 ≈ n_i · t + (r_i × n_i) · ω
```

`r_i` 是测点相对台体姿态参考点的位置，`n_i` 是测量方向。不同高度或横向位置改变旋转产生的位移，平移的共同分量可由作差抵消。实际 IFM 还需对应各自的光程倍率、折返、镜面法向及归零，把上述投影换成相应光路的灵敏度。

`m = F(q; p)` 表示光程前向模型。`m` 是同步光程向量，`q = [X,Y,Z,Rx,Ry,Rz]` 是待求位姿，`p` 是预先标定的常数。工作点附近 `Δm ≈ J·Δq`，其中 `J` 是各读数对六个位姿分量的灵敏度。仅有一道标量时，通常存在无数组给出同一读数的位姿。每一帧要独立局部解出六自由度，需要有效观测的 `J` 满列秩 6。即便有六路，如果光路几何导致响应重复，也可能秩不足或误差放大。

<a name="industrial-method"></a>

## 工业系统常见的解算流程

1. **统一光程和基准。** 同步读取各测量通道的相位变化，按有效波长、光程倍率、方向及零位折算。随环境变化采用对应的补偿。测量基准、Abbe 臂、反射镜安装偏差、束间偏差及面形修正按各通道标定。 [Keysight 三轴 IFM 技术说明](https://www.keysight.com/gb/en/assets/7018-06711/technical-overviews-archived/5964-6190.pdf) · [ASML 台体位置校准 EP2131243B1](https://patents.google.com/patent/EP2131243B1/en)
2. **把多路光程变成位姿。** 对布局规整、姿态小的工作域，可以用差分、均值或预标定矩阵直接解，再加高阶交叉项或查表。ASML 的 US7349069B2 给出两路读数作差再除以基线的测角式，随后用所得转角做位置补偿。US8793099B2 公开了线性项加非线性校准项的六自由度编码器模型。编码器输出与 IFM 光程含义不同，二者使用多观测和标定模型反解位姿的数学结构相通。 [ASML 差分及位置补偿实例](https://patents.google.com/patent/US7349069B2/en) · [ASML 线性与交叉项模型](https://patents.google.com/patent/US8793099B2/en)
3. **按需要保留或联合处理冗余。** 一种做法是指定主测量，其他通道保留给交叉验证和校准。另一种做法是在同一前向模型下按噪声和通道有效性加权，使全部光程的预测与实测之差尽量小。线性近似可用最小二乘，显著非线性时可从直接解或上一个时刻的位姿开始迭代。后一项是测量反演的通用做法。公开资料给出设计实例，具体商用机型的实时实现仍以其资料为准。 [ASML 八个信号与两项冗余的实例](https://patents.google.com/patent/US9383659B2/en)

## ME2 当前八路如何给出六个自由度

| 光程组 | 读数组合 | 接近零位时的主要作用 |
| --- | --- | --- |
| X1、X2 | 均值、横向差分 | X 及 X 侧偏航 `Rzx` |
| X3 与 X1/X2 均值 | 上下束差分，扣除 X3 横向偏移对 Rz 的响应 | 主俯仰 `Ryx` |
| Y1、Y2 | 均值、横向差分 | Y 及 Y 侧偏航 `Rzy` |
| Y3 与 Y1/Y2 均值 | 上下束差分，扣除 Y3 横向偏移对 Rz 的响应 | 滚转 Rx |
| Z1、Z2 | 均值及差分 | Z 及冗余俯仰 `Ryz` |

Level 2《TT-L2-ME-3v0.pdf》文件第 58 页（印刷第 52 页）写明三条 X 光束测 X、Rz、Ry，三条 Y 光束测 Y、Rz、Rx。Level 3《09-TT-L3-WSbook.pdf》文件第 58 页（印刷第 50 页）图 1.60–1.61 显示 X/Y/Z 束组在两个工位的相对布局，正文说明下束 Y3 用于 Rx。两组冗余分别表现为 `Rzx−Rzy` 和 `Ryx−Ryz`。 [C3 光路与转序](WS-IFM-C3%E6%A8%A1%E5%9E%8B%E4%B8%8E%E6%A0%87%E5%AE%9A%E6%A0%B8%E5%AF%B9_v1.md#c3-convention)

### 用当前几何做一个一阶验算

以下量沿用 C3 的名义 v5 光路、归零、光程倍率及符号。长度为 mm，角度为 rad。`x1` 等小写量为光程换算后的读数。上 X 束高度和第三束高度分别为 −43.5、−98.5 mm。在 `Rz=0` 的一阶情形：

```text
mx1 = (x1 + x2)/2 ≈ X - 43.5*Ry
x3                 ≈ X - 98.5*Ry
mx1 - x3           ≈ 55*Ry
```

两读数共有的 X 平移在差分后抵消。差分 55 nm 对应约 1 µrad 的 Ry。若有偏航，先从上束差分估出 Rz，然后处理 X3 的横向偏移。当前模型在同一零位的一阶显式解可写为：

```text
mx1 = (x1 + x2)/2                 my1 = (y1 + y2)/2
Rzx = (x1 - x2)/210               Rzy = (y2 - y1)/180
Ryx = (mx1 - x3 + 20*Rzx)/55      Rx  = (y3 - my1 - 15*Rzy)/68
X   = mx1 + 43.5*Ryx              Y   = my1 - 32.5*Rx
Z   = (z1 + z2)/2 + 50*Rx         Ryz = (z1 - z2)/554
```

以 C3 的物理光程前向式在零位作中心差分，所得八行、六列灵敏度矩阵秩为 6，其中 X/Y 六行的秩为 5。Z 两行近似 `z1 = Z−50*Rx+277*Ry`、`z2 = Z−50*Rx−277*Ry`，所以均值补充唯一的 Z 方向，差分提供额外俯仰约束。令主俯仰为 1 µrad、其余位姿分量为零代入同一前向模型，得到 `mx1−x3=55.00000003 nm`。这些长度系数只用于核对当前名义几何。实机同名参数须使用各自的标定值。 [C3 有限姿态和装调补偿](WS-IFM-C3%E6%A8%A1%E5%9E%8B%E4%B8%8E%E6%A0%87%E5%AE%9A%E6%A0%B8%E5%AF%B9_v1.md#c3-equations)

<a name="c0-ry-input"></a>

## C0 的 Ryz 右端为何还有 Ry

《ifm模型.docx》第 4 页给出的 `Ryz` 右边有 `(4/kze)*X*Ry^2`、`crxya*X*Ry`、`dryya*Ry` 三个含 Ry 的项，还依赖其他位置和姿态。**把这条等式当作显式公式直接求值时，右端的 Ry 确实要有一个估计值。** C0 说明生产控制用 X-IFM 测得的 `Ryx`，Z-IFM 测得的 `Ryz` 则供 Z 模型使用。因此可以由 X/Y 路先得到俯仰估计，再用于同一次采样的 Z 差分补偿。C0 原件没有交代右端变量在目标软件中的实际接线或求解顺序。 [C0 原式和逐项含义](WS-IFM-C0-Ryz%E5%85%AC%E5%BC%8F%E9%80%90%E9%A1%B9%E8%A7%A3%E8%AF%BB_v1.md#ryz-terms)

也可把角度放在未知位姿里，按 `m = F(q; p)` 联立反解。求解器会随测量残差更新候选 `Ry`，而无需在运行中提供额外的真实角度读数。C3 的名义模型由 X/Y 光程求主姿态，固定其余位姿后，以 Z 差分的前向方程求 `Ryz`，保留两路俯仰的测量来源。位置、镜面、光束误差在校准阶段进入 `p`，运行时用于补偿。 [C3 八通道方程](WS-IFM-C3%E6%A8%A1%E5%9E%8B%E4%B8%8E%E6%A0%87%E5%AE%9A%E6%A0%B8%E5%AF%B9_v1.md#c3-equations)
