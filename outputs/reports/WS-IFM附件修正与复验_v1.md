## 修正前后公式

两式组用相同右手坐标，原点为 CAD 晶圆中心 O。设 `a=Rx、b=Ry=Ryx、c=Rz=Rzy`，主动转序为 `RotZ(c)·RotX(a)·RotY(b)`。长度用 mm，角度用 rad。扣除 N00 零位后，X/Y 输入取往返增量之半，Z 输入取直返增量减折返增量之半。均值、差值约定为 `mx1=(x1+x2)/2、mx2=x1−x2、my1=(y1+y2)/2、my2=y2−y1、mz1=(d1+d2)/2、mz2=d1−d2`。复验基准见[光程定义](WS-IFM%E9%99%84%E4%BB%B6%E5%85%AC%E5%BC%8FFreeCAD%E9%AA%8C%E8%AF%81_v1.md#freecad-method)和[名义几何](WS-IFM%E6%A8%A1%E5%9E%8B_v2.md#几何参数表)。

### 角度输入和辅助量

设 `u=mx2/(4cx)`、`v=my2/(4cy)`。附件未给出的两个姿态输入采用原验证的三束解算。两版共用 `Rx、Ryx`，各自计算 `Rzy` 后进入位移式。

```text
nXz = (x3 − mx1 + δy_X·u)/hx
nYz = (y3 − my1 − δx_Y·v)/hy
Rx  = asin(nYz)
Ryx = asin(−nXz/√(1−nYz²))

gx = atan2(u,√(1−u²−nXz²)) − atan2(−nXz·nYz,√(1−nXz²−nYz²))
gy = atan2(v,√(1−v²−nYz²))
λx = Xb/(4cx)
λy = Yb/(4cy)
```

`nXz、nYz` 是两个移动反射面单位法向的 Z 分量。`gx、gy` 是各组三束路径在名义布局下各自给出的 Rz。`hx、hy` 是上束中点至第三束的正值垂直间距，`δy_X、δx_Y` 是第三束减上束中点的有向横向偏置。实机 `Xb、Yb` 需要对应报表所用的带长度单位的同一光路端点。接口运算中暂按本 CAD 名义单程加读数增量处理，29 组的束线差分补偿均为零。

令 `Tx=b²+c²、Ty=a²+c²`，`DX=Kx−kx/2、DY=−Ly+ly/2`，`HX=Kx+ΔKx、HY=Ly+ΔLy`。下式保留原来的束线均值误差定义，扣除旧角度项中由名义几何承担的部分，并按 N00 参考扣除常量。两项都是关于对应平移的一次式。

```text
εX = X·(Ryix0²+Rzix0²)/2 − (X+DX)·(b·Ryix0+c·Rzix0)
εY = Y·(Rxiy0²+Rziy0²)/2 − (Y+DY)·(a·Rxiy0+c·Rziy0)
```

`ΔKx、ΔLy` 只换算后角锥、工位参考点与 CAD 等效光头、O 的有向端点。若 `B0` 为后角锥、`P0` 为工位参考点、`S` 为基础模型等效光头，则 `ΔKx=(x_B0−x_S)+(x_O−x_P0)`，Y 同理。29 组复验中端点按名义对应，`ΔKx=ΔLy=0`。X/Y 的 Abbe 常数仍为正距离。按 O 坐标记录 X-IFM 的 Y 位置偏置 `ee` 与 Y-IFM 的 X 位置偏置 `dd`。

### 六式对照

左栏为附件《ws_ifm_model_corrected.md》第 2 节式 (1)–(6)，以 `a、b、c` 表示三个输入角。粗体标出修正式中的几何改动。右栏式 (1)、(2)、(5) 在三个角已知时对 XYZ 一次联立，使用 3×3 线性方程组。Ryz 使用计算出的 XYZ，取式 (6) 的近零根。

| 项 | 附件原式 | 修正式 |
| --- | --- | --- |
| (1) X | <code>X = sfx·[mx1 + (X+DX)/2·((b−Ryix0)²+(c−Rzix0)²) + Kx·Tx/2 − ee·(c+a·b) − ax·b]</code> | <code><strong>(1−Tx/2)·X + (c+a·b)·Y − b·Z</strong> = sfx·[mx1 + <strong>HX·Tx/2 + ax·b + ee·(c+a·b)</strong> + εX]</code> |
| (2) Y | <code>Y = sfy·[my1 + (Y+DY)/2·((a−Rxiy0)²+(c−Rziy0)²) − Ly·Ty/2 + dd·(c+a·b) + ay·a − sxy·X]</code> | <code><strong>−c·X + (1−Ty/2)·Y + a·Z</strong> = sfy·[my1 + <strong>HY·Ty/2 − ay·a − dd·c</strong> + εY − sxy·X]</code> |
| (3) Rzx | <code>Rzx = u − a·b − λx·[(b−Ryix0)·dRyixh+(c−Rzix0)·dRzixh] + ux·b</code> | <code>Rzx = <strong>gx</strong> − λx·[(b−Ryix0)·dRyixh+(c−Rzix0)·dRzixh] + ux·b</code> |
| (4) Rzy | <code>Rzy = v − λy·[(a−Rxiy0)·dRxiyh+(c−Rziy0)·dRziyh] + wy·a</code> | <code>Rzy = (<strong>gy</strong> − λy·[(a−Rxiy0)·dRxiyh−Rziy0·dRziyh] + wy·a)/(1+λy·dRziyh)</code> |
| (5) Z | <code>Z = sfz·[mz1 + X·a·c + szxa·X + szya·Y</code><br><code> + ezxa·a + ezya·b + ezza·c</code><br><code> + czxxa·X·a + czxya·X·b + czxza·X·c + czyya·Y·b</code><br><code> + dzxxa·a² + dzyya·b² + dzzza·c² + dzxza·a·c]</code> | <code>Z = sfz·[mz1 <strong>+ Y·a − X·a·c + Z·a²</strong> + szxa·X + szya·Y</code><br><code> + ezxa·a + ezya·b + ezza·c</code><br><code> + czxxa·X·a + czxya·X·b + czxza·X·c + czyya·Y·b</code><br><code> + dzxxa·a² + dzyya·b² + dzzza·c² + dzxza·a·c]</code> |
| (6) Ryz | <code>Ryz = sfryz·[mz2/kze·(1−2Z/kze) + (2X/kze)·a² + (4X/kze)·b²</code><br><code> + srxa·X + srya·Y + srza·Z + erxa·a + erza·c</code><br><code> + crxxa·X·a + crxya·X·b + crxza·X·c</code><br><code> + drxxa·a² + drxza·a·c + dryya·b²]</code> | <code>Ryz = sfryz·[<strong>θ</strong> + srxa·X + srya·Y + srza·Z + erxa·a + erza·c</code><br><code> + crxxa·X·a + crxya·X·b + crxza·X·c</code><br><code> + drxxa·a² + <strong>(drxza−drxza_geo)·a·c</strong> + dryya·b²]</code> |

式 (6) 的 `θ`、`A`、`B`、`C` 是当前名义几何中从 Z 差分反解的转角及中间系数。

```text
drxza_geo = −2·HZ/kze
A = 3·X
B = kze + 2·Z − 2·(Y−yZ)·a
C = X·a² − kze·drxza_geo·a·c − mz2
θ = −2·C/[B+√(B²−4·A·C)]
```

`yZ` 是 Z 两参考头的平均 Y 坐标，`HZ` 是两参考头 X 向间距的一半。名义几何取 `yZ=−50 mm、HZ=490 mm`。在此布局中几何 Rx·Rz 贡献已经计入 `C`，所以在式 (6) 只再加总系数与几何系数的差。根式要求 `B>0`、`B²−4AC≥0`，在 `A=0` 时得到 `−C/B`。29 组中 `B` 在 544–564 mm，XYZ 体系数矩阵行列式在 0.9999994–1.0000001。

| 项 | 改动依据 |
| --- | --- |
| (1)、(2) | 直接光程沿旋转后的镜面法向观测。修正式左端把 XYZ 在 X/Y 法向上的分量展开到转角二阶，右端由正距离重新计算 Abbe 项和死程项。定 Rz 改变 Y 时，X 光路读数变化通过左侧 Y 项补偿。 |
| (3)、(4) | 用三束恢复的法向分量和转序计算偏航。式 (4) 将原式中 `c=Rzy` 的一次自项移到左侧并除以系数。上束差分误差系数仍按附件原有补偿项接入。 |
| (5) | 定 Z、定 Rx 移动 Y 时，光程高度随 Y 变化。显式加入 `Y·Rx`，按坐标变换修正 X·Rx·Rz 的符号。`Z·Rx²` 是使用实际 Y 而非 Y 通道读数表达该投影时的二阶项。其余标定系数的自变量保持原定义。 |
| (6) | 用随 Z/Y/Rx 变化的有效臂和近零根替代倒数的一阶近似，同时保留角度尺度、位置斜率和转角补偿。Ryz 在本报告中作为 Z 通道的冗余估计。式 (5) 的几何俯仰量取 Ryx。附件另称生产中 Ryz 参与 Z 补偿，实际接入的项和标定基准需由控制器资料核对。 |

## 逐项校准常数核对

逐项包括附件表 2 的 23 项、表 3 的 26 项以及式 (6) 的有效臂 `kze`，共 50 项。下表的“几何换算”表示同一物理量在匹配端点、轴向符号和单位后可作为输入。“同基准可用”用于零倾扫位时保持原形式的斜率项。“核对旧拟合”表示公式保留同名、同自变量的参数位置，但旧值可能吸收了原公式缺失的几何项，需用目标版本的拟合定义或原观测复核。“待查写入”表示找到相关校准功能或部件定义，当前资料尚未确认此字段的实际写入来源。

复验还在一组混合读数上用显式的非零试验量扰动每个字段，50 项均影响至少一个模型输出。该试验确认输入字段接到了公式；29 组 FreeCAD 仅检验当前名义布局和指定姿态范围。WGTD 样本为 rel.3.4.0 E 侧 `wse_chuck1_if_model_parameters` 的候选结果，原页的示例状态为 `Not Saved`。来源为《12-TT-L3-L3-ME_book.pdf》文件第 91–92 页（印刷第 83–84 页），图 2.85–2.86、表 2.2。[项目及原页索引](WS-IFM%E6%9C%BA%E5%99%A8%E5%B8%B8%E6%95%B0%E6%A0%A1%E5%87%86%E9%A1%B9%E7%9B%AE_v1.md#core-calibrations) · [WGTD 报表字段](WS-IFM%E6%9C%BA%E5%99%A8%E5%B8%B8%E6%95%B0%E6%A0%A1%E5%87%86%E9%A1%B9%E7%9B%AE_v1.md#wgtd-fields)
