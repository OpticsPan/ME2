# WS-IFM 正交测高光路一致性修订

日期 2026-11-20

- 核查 [布局图 v2](../outputs/WS-IFM%E5%87%A0%E4%BD%95%E5%B8%83%E5%B1%80%E5%9B%BE_v2.svg)，发现 M 侧等轴图的两条 Z 光路均沿 X 入射，理想 45° 镜下两条光斑均随 X 行程移动。俯视图却标注其中一路覆盖 Y 行程。
- 在 [布局图 v3](../outputs/WS-IFM%E5%87%A0%E4%BD%95%E5%B8%83%E5%B1%80%E5%9B%BE_v3.svg) 中改为分别沿 X 和 Y 入射。每路配横跨其入射方向的台体 45° 镜，以及沿同一入射轴延伸的框架 Z 长镜。子图 1 和 4 使用同组坐标，E 侧沿用同一原则，Z 剖面分成 X–Z 与 Y–Z。
- 采用固定收发头、理想镜面、台体平移的模型检查折转方向和框架上的光斑。纯 X 平移只移动 X 路光斑，纯 Y 平移只移动 Y 路光斑。图示标明实机 Z1/Z2 配属及姿态解算按配置核对。
